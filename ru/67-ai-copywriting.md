# AI копирайтинг через промпт-конвейер

**Модуль:** Content Factory AI | **Время:** ~25 мин теории + 40 мин практики

---

## Суть урока

AI-копирайтинг в лоб («напиши мне пост») даёт ChatGPT-текст, который все узнают и никто не читает — правильный подход это промпт-конвейер из нескольких шагов и файл brand voice, который учит Claude писать в твоём стиле.

🎨 **Образ:** Попросить Claude написать текст без контекста — как попросить художника нарисовать «что-нибудь красивое». Результат будет, но не твоим. Промпт-конвейер — это техническое задание художнику: стиль, палитра, формат, настроение, референсы. Тогда получаешь не «что-нибудь», а именно то, что хотел.

---

## Ключевые концепции

- ChatGPT-паттерн легко распознать и как его избежать через конкретность
- Промпт-конвейер: идея → outline → draft → edit → финал (5 шагов)
- Brand voice файл — постоянный контекст, который делает Claude «тобой»
- Форматы: Telegram, YouTube скрипты, лендинги, email (у каждого свои правила)
- Батчевая генерация: 30 постов за раз через один промпт-пакет
- AI-детекторы обходятся конкретикой, не стилем скрытия

---

## Теория

### Почему ChatGPT-копирайтинг выглядит как ChatGPT

Есть стандартный набор слов и конструкций, которые AI выдаёт по умолчанию, потому что они часто встречаются в обучающих данных:

```
❌ AI-паттерны которые убивают доверие:
- "В современном мире..."
- "В эпоху цифровых технологий..."
- "Unleash your potential"
- "Game-changing solution"
- "Leverage your strengths"
- "It's important to note that..."
- Три пункта с тире и восклицательным знаком в конце
- Первое предложение с риторическим вопросом
```

🎨 **Образ:** Это как суповой набор из пакета — вроде суп, но все знают что из пакета. Настоящий суп пахнет иначе, выглядит иначе, ощущается иначе. Правильный AI-копирайтинг должен пахнуть тобой, не пакетом.

**Почему так происходит:**
Claude без контекста оптимизирует под «среднего читателя среднего текста». Твоя задача — дать столько специфики, чтобы «средний» стал «твоим».

---

### Промпт-конвейер: 5 шагов от идеи до финала

Вместо одного большого промпта — последовательность маленьких точных шагов.

**Шаг 1: Идея → Угол**

```
Тема: [что хочешь написать]
Аудитория: [кто будет читать]
Задача текста: [что читатель должен сделать/почувствовать]
Угол: [неочевидный взгляд на тему]

Предложи 5 разных углов для поста на эту тему.
Каждый угол — одно предложение. Без воды.
```

**Шаг 2: Угол → Outline**

```
Выбранный угол: [скопировал из шага 1]
Формат: [Telegram пост / YouTube скрипт / email / лендинг]
Длина: [количество слов или знаков]

Напиши структуру (outline) без написания текста.
Только заголовки разделов и одна строка о чём каждый.
```

**Шаг 3: Outline → Draft**

```
[Вставить outline из шага 2]
[Вставить brand voice файл или краткое описание стиля]

Напиши черновик строго по структуре.
Конкретика вместо общих слов.
Примеры из реальной жизни.
```

**Шаг 4: Draft → Edit**

```
[Вставить черновик]

Проверь и улучши:
1. Первое предложение — захватывает? Перепиши если нет
2. Есть ли AI-клише? Замени конкретикой
3. Каждый абзац несёт новую мысль? Убери дублирование
4. Призыв к действию в конце — конкретный и один?
```

**Шаг 5: Edit → Финал**

```
[Черновик после правок]

Последняя проверка:
- Длина соответствует формату?
- Тон соответствует [платформе]?
- Один читатель — одно действие в конце?

Выдай финальный текст.
```

Такой конвейер занимает дольше одного запроса, но результат качественно другой.

### Brand voice файл — твой стиль как документ

Brand voice — это файл, который ты даёшь Claude перед каждым написанием. Он описывает как ты пишешь, что не пишешь никогда, твою аудиторию и примеры твоих лучших текстов.

**Структура файла `brand-voice.md`:**

```markdown
# Brand Voice — [Имя / Название проекта]

## Кто я
[2-3 предложения кто ты, чем занимаешься, для кого]

## Аудитория
- Кто: [описание]
- Что им важно: [3-5 пунктов]
- Что их раздражает: [2-3 пункта]

## Тон
- Пишу как: [разговорно / деловито / неформально / экспертно]
- НЕ пишу: [coaching-сленг / жаргон / цифры без источника]
- Примеры тона который мне нравится: [ссылки или образцы]

## Стиль
- Предложения: [короткие / средние / длинные / смешанные]
- Абзацы: [1-3 строки / больше]
- Структура: [списки / проза / смешанно]
- Эмодзи: [нет / редко / активно]

## Запрещённые слова и фразы
- "синергия", "инсайт", "выйди из зоны комфорта"
- "важно отметить", "в современном мире"
- [добавь свои]

## Примеры моих лучших текстов
[Вставь 2-3 лучших своих поста/письма]

## Формулы которые работают для меня
- Формула поста: [хук → история → вывод → вопрос]
- Формула email: [тема-боль → история → решение → CTA]
```

Этот файл идёт в `areas/marketing/brand-voice.md` по PARA-системе (подробно: [Философия папок — PARA система для AI-предпринимателя](66-folder-structure-philosophy.md)). Чтобы не вставлять файл каждый раз, его можно оформить как навык (Skill) Claude: навыки доступны на всех тарифах на октябрь 2026.

🎨 **Образ:** Brand voice — это как инструкция для нового копирайтера в команде. Без неё он пишет «нормально». С ней — пишет как ты.

### Форматы: у каждого свои правила

**Telegram пост (до 1000 знаков):**

```
Правила:
- Первая строка = крючок (без вводных слов)
- Абзацы по 1-2 строки с пустой строкой между ними
- Один вывод или вопрос в конце
- Эмодзи — только если это твой стиль

Промпт:
"Напиши Telegram пост до 800 знаков.
Тема: [тема]. Хук в первой строке без вводных.
Абзацы по 2 строки максимум. 
Без восклицательных знаков в конце."
```

**YouTube скрипт (8-12 минут = ~1200-1800 слов):**

```
Структура:
[0:00-0:30] — Хук: что получит зритель
[0:30-1:30] — Проблема: почему это важно
[1:30-8:00] — Основной контент: 3-5 блоков
[8:00-9:30] — Резюме + практика
[9:30-10:00] — CTA: подписка / ссылка

Промпт:
"Напиши YouTube скрипт на 10 минут.
Тема: [тема]. Хук первые 30 секунд.
Разговорный стиль. Обозначь тайм-коды.
Каждый блок с переходом к следующему."
```

**Landing page copy:**

```
Структура:
Hero: заголовок + подзаголовок + CTA
Problem: боль читателя (3 пункта)
Solution: как ты решаешь
How it works: 3 шага
Proof: социальные доказательства
FAQ: 5 вопросов
CTA: финальный призыв

Промпт:
"Напиши копирайтинг лендинга.
Продукт: [описание]. 
ЦА: [описание].
Главный страх клиента: [страх].
Главный результат: [результат].
Тон: [профессиональный / дружелюбный]."
```

### Батчевая генерация: 30 постов за раз

Вместо написания по одному — генерируй пачкой:

```
У меня контент-план на месяц. Темы:
1. [тема 1]
2. [тема 2]
...
30. [тема 30]

Brand voice: [вставить или указать файл]
Формат: Telegram пост, до 600 знаков каждый

Напиши все 30 постов по очереди.
Нумеруй каждый. 
Между постами — разделитель ---
```

Результат: 30 готовых постов за один запрос. Потом редактируешь лучшие, остальные в архив.

**Важно:** Батч-режим снижает качество каждого поста. Используй для черновиков, не для финала.

### Как избежать AI-детекторов

Правда простая: AI-детекторы ловят не «AI-стиль», они ловят предсказуемость. При этом они ошибаются в обе стороны и не доказывают авторство, поэтому цель не обойти проверку, а написать текст с конкретикой, который приятно читать.

Что делает текст предсказуемым:

- Общие фразы без конкретики
- Одинаковая длина предложений
- Отсутствие разговорных конструкций
- Ноль личного опыта

**Решение — конкретика, не стиль скрытия:**

```
❌ "Многие предприниматели сталкиваются с проблемами масштабирования"
✅ "В апреле у меня упала конверсия с 4% до 1.8% — вот что я нашёл"

❌ "Искусственный интеллект меняет бизнес"
✅ "Claude написал 47 постов за вечер. Я отредактировал 12. Вот какие."
```

Добавь в промпт:

```
В тексте добавь:
- Одну конкретную цифру из реального опыта
- Одну неожиданную деталь
- Одно предложение как будто говоришь вслух
```

## Практика

1. Создай файл `brand-voice.md` для своего проекта (используй шаблон из урока):

```bash
mkdir -p ~/workspace/areas/marketing
# Создай файл и заполни все разделы
```

2. Напиши первый Telegram пост через конвейер из 5 шагов:

```
Тема: [выбери что-то из своего контента]
Запускай каждый шаг отдельным промптом
Сохрани результат каждого шага
```

3. После конвейера — попроси Claude оценить финальный текст:

```
Оцени этот текст по шкале 1-10 по критериям:
- Конкретность (нет общих слов)
- Соответствие brand voice
- Сила первого предложения
- Ясность призыва к действию

Для каждого критерия — оценка и одно предложение что улучшить.
```

4. Сгенерируй батч из 10 черновиков постов:

```bash
# Создай файл с темами
echo "1. [тема 1]
2. [тема 2]
...
10. [тема 10]" > content-plan.txt
```

Дай Claude список тем + brand voice, получи 10 черновиков, выбери лучшие 3.

5. Для продвинутых — создай скрипт-генератор на Python:

```python
import os
import anthropic

client = anthropic.Anthropic()
os.makedirs("posts", exist_ok=True)

with open("brand-voice.md", encoding="utf-8") as f:
    brand_voice = f.read()

topics = [
    "тема 1",
    "тема 2",
    "тема 3",
]

for i, topic in enumerate(topics, 1):
    message = client.messages.create(
        model="claude-sonnet-5-5",  # актуальные идентификаторы моделей: документация Anthropic
        max_tokens=1024,
        messages=[{
            "role": "user",
            "content": f"""Brand voice:
{brand_voice}

Напиши Telegram пост на тему: {topic}
До 600 знаков. Хук в первой строке."""
        }]
    )
    
    with open(f"posts/post-{i:02d}.md", "w", encoding="utf-8") as f:
        f.write(f"# Пост {i}: {topic}\n\n")
        f.write(message.content[0].text)
    
    print(f"Пост {i} готов")
```

## Ключевые выводы

> Промпт-конвейер из 5 шагов производит текст другого качества, чем один большой промпт — как разница между фастфудом и ресторанной едой: обе из продуктов, но процесс разный.

> Brand voice файл — это инвестиция один раз: напиши его хорошо, и каждый следующий текст через Claude будет ближе к твоему голосу без дополнительных объяснений.

> AI-детекторы ловят предсказуемость, а не «AI-стиль» — добавь конкретные цифры, личный опыт и разговорные конструкции, и текст будет живым независимо от инструмента написания.
