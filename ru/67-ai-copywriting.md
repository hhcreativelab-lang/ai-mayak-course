# AI копирайтинг через промпт-конвейер

**Время:** ~25 мин теории + 40 мин практики

---

## Суть урока

Если попросить AI в лоб «напиши мне пост», получится безликий текст, который все узнают и никто не читает. Работает другой подход: цепочка из нескольких запросов (промпт-конвейер) и файл с описанием твоего стиля, который учит Claude писать как ты. Такой файл называют «голос бренда» (по-английски brand voice).

Всё в этом уроке делается в обычном чате Claude, в браузере или в телефоне. Программировать не нужно. Задание с кодом в конце практики необязательное: оно для тех, кто строит свои инструменты.

🎨 **Образ:** Попросить Claude написать текст без контекста — как попросить художника нарисовать «что-нибудь красивое». Результат будет, но не твоим. Промпт-конвейер — это техническое задание художнику: стиль, палитра, формат, настроение, образцы. Тогда получаешь не «что-нибудь», а именно то, что хотел.

---

## Ключевые концепции

- Шаблонный текст AI легко узнать; спасает конкретика
- Промпт-конвейер: идея → план → черновик → правка → финал (5 шагов)
- Файл «голос бренда» (brand voice) — постоянный контекст, с которым Claude пишет как ты
- Форматы: пост в Telegram, сценарий для YouTube, продающая страница (лендинг), письмо. У каждого свои правила
- Генерация пачкой: 30 черновиков постов одним запросом
- AI-детекторы: помогает конкретика, а не маскировка

## Теория

### Почему ChatGPT-копирайтинг выглядит как ChatGPT

Есть стандартный набор слов и конструкций, которые AI выдаёт по умолчанию, потому что они часто встречаются в текстах, на которых он учился:

```
❌ Шаблоны AI, которые убивают доверие:
- «В современном мире...»
- «В эпоху цифровых технологий...»
- «Раскрой свой потенциал»
- «Решение, которое меняет правила игры»
- «Используй свои сильные стороны»
- «Важно отметить, что...»
- Три пункта с тире и восклицательным знаком в конце
- Первое предложение с риторическим вопросом
```

🎨 **Образ:** Это как суп из пакетика: вроде суп, но все знают, что из пакетика. Настоящий суп пахнет иначе, выглядит иначе, ощущается иначе. Хороший текст с AI должен пахнуть тобой, а не пакетиком.

**Почему так происходит:**
Claude без контекста пишет для «среднего читателя среднего текста». Твоя задача — дать столько конкретики, чтобы «средний» стал «твоим».

---

### Промпт-конвейер: 5 шагов от идеи до финала

Вместо одного большого промпта — последовательность маленьких точных шагов. Каждый шаг — отдельное сообщение в одном и том же чате.

**Шаг 1: Идея → Угол подачи**

```
Тема: [что хочешь написать]
Аудитория: [кто будет читать]
Задача текста: [что читатель должен сделать/почувствовать]
Угол: [неочевидный взгляд на тему, если он уже есть; если нет, удали эту строку]

Предложи 5 разных углов подачи для поста на эту тему.
Каждый угол — одно предложение. Без воды.
```

**Шаг 2: Угол → План**

```
Выбранный угол: [скопировал из шага 1]
Формат: [пост в Telegram / сценарий для YouTube / письмо / продающая страница]
Длина: [количество слов или знаков]

Напиши план текста, сам текст пока не пиши.
Только заголовки разделов и одна строка о том, что в каждом.
```

**Шаг 3: План → Черновик**

```
[Вставить план из шага 2]
[Вставить файл «голос бренда» или краткое описание стиля]

Напиши черновик строго по плану.
Конкретика вместо общих слов.
Примеры и цифры бери только из того, что я дал. Если их не хватает, спроси меня.
```

**Шаг 4: Черновик → Правка**

```
[Вставить черновик]

Проверь и улучши:
1. Первое предложение — захватывает? Перепиши если нет
2. Есть ли AI-клише? Замени конкретикой
3. Каждый абзац несёт новую мысль? Убери повторы
4. Призыв к действию в конце — конкретный и один?
```

**Шаг 5: Правка → Финал**

```
[Черновик после правок]

Последняя проверка:
- Длина соответствует формату?
- Тон соответствует [платформе]?
- Один читатель — одно действие в конце?

Выдай финальный текст.
```

Такой конвейер занимает больше времени, чем один запрос, но текст получается заметно лучше. Перед публикацией прочитай финал сам: факты, цифры и имена проверяешь ты.

### Файл «голос бренда» (brand voice) — твой стиль как документ

«Голос бренда» — это файл, который ты даёшь Claude перед каждым текстом. Он описывает, как ты пишешь, чего не пишешь никогда, кто твоя аудитория, и содержит примеры твоих лучших текстов.

**Структура файла `brand-voice.md`:**

```markdown
# Голос бренда — [Имя / Название проекта]

## Кто я
[2-3 предложения: кто ты, чем занимаешься, для кого]

## Аудитория
- Кто: [описание]
- Что им важно: [3-5 пунктов]
- Что их раздражает: [2-3 пункта]

## Тон
- Пишу как: [разговорно / деловито / неформально / экспертно]
- НЕ пишу: [жаргон коучей / профессиональный жаргон / цифры без источника]
- Примеры тона, который мне нравится: [ссылки или образцы]

## Стиль
- Предложения: [короткие / средние / длинные / смешанные]
- Абзацы: [1-3 строки / больше]
- Структура: [списки / проза / смешанно]
- Эмодзи: [нет / редко / активно]

## Запрещённые слова и фразы
- «синергия», «инсайт», «выйди из зоны комфорта»
- «важно отметить», «в современном мире»
- [добавь свои]

## Примеры моих лучших текстов
[Вставь 2-3 лучших своих поста/письма]

## Формулы, которые работают для меня
- Формула поста: [крючок → история → вывод → вопрос]
- Формула письма: [тема-боль → история → решение → призыв к действию]
```

Крючок — первая фраза, которая цепляет читателя. Призыв к действию — одно действие, о котором ты просишь читателя в конце.

`brand-voice.md` — обычный текстовый файл: набери его в любом редакторе или в заметках и вставляй его текст в начало чата. Если ты раскладываешь файлы по системе PARA, его место — `areas/marketing/brand-voice.md` (это урок из библиотеки, он необязателен: [Философия папок — PARA система для AI-предпринимателя](66-folder-structure-philosophy.md)). Чтобы не вставлять файл каждый раз, его можно оформить как навык (Skill) Claude: это сохранённая инструкция, которую Claude подключает сам, когда она подходит к задаче. Навыки лежат в разделе Customize → Skills («Настроить» → «Навыки») и на октябрь 2026 доступны на всех тарифах.

🎨 **Образ:** Файл «голос бренда» — как инструкция для нового копирайтера в команде. Без неё он пишет «нормально». С ней пишет как ты.

### Форматы: у каждого свои правила

**Пост в Telegram (до 1000 знаков):**

```
Правила:
- Первая строка = крючок (без вводных слов)
- Абзацы по 1-2 строки с пустой строкой между ними
- Один вывод или вопрос в конце
- Эмодзи — только если это твой стиль

Промпт:
"Напиши пост для Telegram до 800 знаков.
Тема: [тема]. Крючок в первой строке, без вводных слов.
Абзацы по 2 строки максимум.
Без восклицательных знаков в конце."
```

**Сценарий для YouTube (8-12 минут = ~1200-1800 слов):**

```
Структура:
[0:00-0:30] — Крючок: что получит зритель
[0:30-1:30] — Проблема: почему это важно
[1:30-8:00] — Основная часть: 3-5 блоков
[8:00-9:30] — Итог + практика
[9:30-10:00] — Призыв к действию: подписка / ссылка

Промпт:
"Напиши сценарий ролика для YouTube на 10 минут.
Тема: [тема]. Крючок в первые 30 секунд.
Разговорный стиль. Обозначь тайм-коды.
Каждый блок с переходом к следующему."
```

**Текст продающей страницы (лендинга):**

```
Структура:
Первый экран: заголовок + подзаголовок + призыв к действию
Проблема: боль читателя (3 пункта)
Решение: как ты решаешь
Как это работает: 3 шага
Доказательства: отзывы, кейсы, логотипы клиентов (только настоящие)
Вопросы и ответы: 5 вопросов
Призыв к действию: финальный

Промпт:
"Напиши текст продающей страницы.
Продукт: [описание].
Целевая аудитория: [описание].
Главный страх клиента: [страх].
Главный результат: [результат].
Тон: [профессиональный / дружелюбный]."
```

💡 Доказательства должны быть настоящими. Не давай AI придумывать отзывы: вставь слова, которые клиенты действительно сказали.

### Генерация пачкой: 30 постов за раз

Вместо постов по одному можно попросить сразу пачку (по-английски batch):

```
У меня контент-план на месяц. Темы:
1. [тема 1]
2. [тема 2]
...
30. [тема 30]

Голос бренда: [вставить текст файла или приложить файл]
Формат: пост для Telegram, до 600 знаков каждый

Напиши все 30 постов по очереди.
Нумеруй каждый.
Между постами — разделитель ---
```

Результат: 30 черновиков постов за один запрос. Лучшие дорабатываешь, остальные в архив.

**Важно:** при генерации пачкой качество каждого поста ниже. Используй её для черновиков, не для финала.

### А что с AI-детекторами

AI-детектор — сервис, который пытается угадать, написан ли текст машиной. Правда простая: детекторы реагируют не на «AI-стиль», а на предсказуемость. При этом они ошибаются в обе стороны и не доказывают авторство, поэтому цель не обойти проверку, а написать текст с конкретикой, который приятно читать.

Что делает текст предсказуемым:

- Общие фразы без конкретики
- Одинаковая длина предложений
- Отсутствие разговорных оборотов
- Ноль личного опыта

**Решение — конкретика, а не маскировка:**

```
❌ «Многие предприниматели сталкиваются с проблемами роста»
✅ «В апреле доля покупателей среди посетителей упала у меня с 4% до 1,8%. Вот что я нашёл»

❌ «Искусственный интеллект меняет бизнес»
✅ «Claude написал 47 постов за вечер. Я отредактировал 12. Вот какие»
```

Добавь в промпт:

```
В тексте добавь:
- Одну конкретную цифру из моего опыта: [впиши цифру]
- Одну неожиданную деталь: [впиши деталь]
- Одно предложение так, как будто говоришь вслух
```

Цифру и деталь дай Claude сам. Если оставить их на его усмотрение, он может просто придумать их (уверенная выдумка AI называется галлюцинацией), а придуманная цифра в твоём тексте хуже, чем никакой.

## Практика

1. Создай файл `brand-voice.md` для своего проекта по шаблону из урока. Подойдёт любой текстовый редактор или заметки: файл нужен, чтобы вставлять его текст в чат. Готово, когда заполнены все разделы и в примерах стоят 2–3 твоих настоящих текста. Команда ниже нужна только тем, кто работает в терминале и раскладывает файлы по папкам; остальные её пропускают:

```bash
mkdir -p ~/workspace/areas/marketing
# Создай файл и заполни все разделы
```

2. Напиши первый пост для Telegram через конвейер из 5 шагов:

```
Тема: [выбери что-то из своей работы]
Запускай каждый шаг отдельным сообщением
Сохраняй результат каждого шага
```

3. После конвейера попроси Claude оценить финальный текст:

```
Оцени этот текст по шкале 1-10 по критериям:
- Конкретность (нет общих слов)
- Соответствие моему голосу бренда
- Сила первого предложения
- Ясность призыва к действию

Для каждого критерия — оценка и одно предложение, что улучшить.
```

4. Сгенерируй пачку из 10 черновиков постов. Список из 10 тем напиши прямо в чате. Команда ниже создаёт такой же список файлом в терминале, она необязательна:

```bash
# Создай файл с темами
echo "1. [тема 1]
2. [тема 2]
...
10. [тема 10]" > content-plan.txt
```

Дай Claude список тем и текст файла «голос бренда», получи 10 черновиков, выбери лучшие 3.

5. Необязательно, для тех, кто строит свои инструменты и уже работает с кодом: скрипт-генератор на Python. Остальные это задание пропускают, урок без него пройден.

```python
import os
import anthropic

client = anthropic.Anthropic()
os.makedirs("posts", exist_ok=True)

with open("brand-voice.md", encoding="utf-8") as f:
    brand_voice = f.read()

topics = [
    "тема 1",
    "тема 2",
    "тема 3",
]

for i, topic in enumerate(topics, 1):
    message = client.messages.create(
        model="claude-sonnet-5-5",  # актуальные идентификаторы моделей: документация Anthropic
        max_tokens=4000,  # с запасом: в этот лимит входит и «размышление» модели
        messages=[{
            "role": "user",
            "content": f"""Голос бренда:
{brand_voice}

Напиши пост для Telegram на тему: {topic}
До 600 знаков. Крючок в первой строке."""
        }]
    )
    # В ответе могут быть блоки «размышления»: берём только текст
    text = "".join(block.text for block in message.content if block.type == "text")

    with open(f"posts/post-{i:02d}.md", "w", encoding="utf-8") as f:
        f.write(f"# Пост {i}: {topic}\n\n")
        f.write(text)

    print(f"Пост {i} готов")
```

Скрипт берёт ключ API из переменной окружения `ANTHROPIC_API_KEY`. Никогда не вставляй ключ в сам код.

## Инструменты и ресурсы

- **[Claude.ai](https://claude.ai)** — основной инструмент для конвейера
- **[Anthropic API](https://claude.com/api)** — для генерации пачкой через код (цены и модели: [Актуальное сейчас](https://aimayak.com/ru/now/))
- **[Hemingway App](https://hemingwayapp.com)** — проверка читаемости текста (рассчитан на английский текст)
- **[QuillBot](https://quillbot.com)** — перефразирование для финальной шлифовки (по справке сервиса, русский язык поддерживается)
- **[GPTZero](https://gptzero.me)** — AI-детектор: можно прогнать через него свой текст и посмотреть, где он звучит шаблонно

## Ключевые выводы

> Промпт-конвейер из 5 шагов даёт текст другого качества, чем один большой промпт. Это как разница между фастфудом и ресторанной едой: обе из продуктов, но процесс разный.

> Файл «голос бренда» делается один раз: напиши его хорошо, и каждый следующий текст через Claude будет ближе к твоему голосу без дополнительных объяснений.

> AI-детекторы реагируют на предсказуемость, а не на «AI-стиль»: добавь настоящие цифры, личный опыт и разговорные обороты, и текст будет живым, чем бы ты его ни писал.
