# AI видеогенерация — Runway, Kling, Luma и другие

**Модуль:** Content Factory AI | **Время:** ~25 мин теории + 35 мин практики

---

## Суть урока

Раньше короткий ролик требовал оператора, монтажёра и студии. Сегодня ты открываешь вкладку браузера, пишешь несколько предложений — и через несколько минут получаешь клип. Не Голливуд, но для соцсетей, лендинга и рекламы часто достаточно. В этом уроке разбираем платформы на октябрь 2026 и строим рабочий конвейер: Claude пишет сценарий и промпты (промпт — запрос к AI) → Runway генерирует видео → FFmpeg собирает ролик. Kling подключается по тому же принципу.

🎨 **Образ:** Раньше каждый видеоролик — это ручная работа гончара: долго, дорого, каждый раз с нуля. Теперь это как 3D-принтер: ты вводишь параметры — получаешь изделие. Качество чуть ниже ручной работы, зато скорость в сотни раз быстрее.

---

## Ключевые концепции

- **Text-to-Video** — видео из текстового описания сцены
- **Image-to-Video** — анимация статичного фото или рендера (оживление)
- **Video-to-Video** — смена стиля или окружения существующего видео
- **Motion Brush** — инструмент ранних версий Runway для точного управления движением по областям кадра
- **Keyframe анимация** — задаёшь первый и последний кадр, AI строит переход
- **Consistency проблема** — персонажи могут «плыть» от сцены к сцене: как с этим бороться
- **Коммерческое лицензирование** — что можно и нельзя делать с сгенерированными видео

### Runway — рабочая лошадь с API

Runway — американский стартап и один из лидеров рынка с сильным API. Именно это делает его удобным для автоматизации. На октябрь 2026 флагманская модель — Gen-4.5; на платных тарифах доступны и партнёрские модели (например, Kling 3.0, Seedance 2.0, Nano Banana Pro), а Aleph 2.0 правит готовое видео.

**Что умеет:**

**Text-to-Video.** Пишешь промпт — получаешь клип 5–10 секунд. Runway отлично понимает операторский язык: «slow dolly in», «aerial establishing shot», «rack focus from foreground to background». Пиши как режиссёр — получай как режиссёр.

**Image-to-Video.** Загружаешь фото товара или интерьера — Runway анимирует его с сохранением стиля. Это killer feature для недвижимости и e-commerce: статичные фото оживают для рекламы.

**Motion Brush** (инструмент ранних версий Runway; проверь, есть ли он в актуальных моделях). Рисуешь поверх кадра и указываешь направление движения для каждой зоны. Вода течёт, листья шевелятся, а всё остальное стоит — полный контроль.

**Цены (на октябрь 2026):**

- Бесплатный план: 125 кредитов единоразово
- Платные тарифы: от $12 в месяц при годовой оплате
- Расход зависит от модели: Gen-4.5 тратит 12 кредитов за секунду видео
- Актуально: [runway.com/pricing](https://runway.com/pricing), [Актуальное сейчас](https://aimayak.com/ru/now/)

**Ключевое для нас:** официальный API (эй-пи-ай — интерфейс программирования). Можно автоматизировать полностью: Claude генерирует промпты → скрипт (программный код для автоматизации) отправляет в Runway → видео скачиваются сами.

**Коммерческая лицензия:** по данным страницы тарифов Runway, коммерческое использование разрешено на платных тарифах. Перед сдачей работы клиенту перечитай условия.

```python
from runwayml import RunwayML, TaskFailedError  # pip install runwayml

# Ключ API берётся из переменной окружения RUNWAYML_API_SECRET
client = RunwayML()


def generate_video(prompt: str, duration: int = 5) -> str:
    """
    Генерирует видео по тексту через Runway API.
    Возвращает URL готового видео.
    Имена моделей и допустимые параметры меняются: сверяй с docs.dev.runwayml.com.
    Если выбранная модель принимает только кадр-основу, используй
    client.image_to_video.create(...) с параметром prompt_image.
    """
    try:
        task = client.text_to_video.create(
            model="gen4.5",         # флагманская модель на октябрь 2026
            prompt_text=prompt,
            ratio="1280:720",       # 16:9 горизонтальное
            duration=duration,
        ).wait_for_task_output()    # SDK сам опрашивает статус задачи
    except TaskFailedError as error:
        raise RuntimeError(f"Ошибка генерации: {error.task_details}")

    return task.output[0]
```

### Kling — сильное движение людей

Kling — платформа от Kuaishou (Китай). Рабочая линейка на октябрь 2026 — Kling VIDEO 3.0: ролики от 3 до 15 секунд, нативный 4K, звук с липсинком, несколько планов в одном запросе. В конце сентября 2026 анонсирована Kling 4.0 (до 30 секунд за один проход, до 10 ключевых кадров, стереозвук); широкий запуск ожидается в октябре.

**Сильные стороны:**

- Движение людей: жесты, мимика, походка (по отзывам; проверь на своих промптах)
- Ролики до 15 секунд на VIDEO 3.0, у версии 4.0 заявлено до 30
- Звук с липсинком прямо в видео
- API доступен (документация: [kling.ai/document-api](https://kling.ai/document-api))

**Ограничения:**

- Скорость генерации зависит от нагрузки и тарифа: засеки время на своих задачах
- Вопросы хранения данных для EU/US клиентов (уточняй по договору)

**Цены:** есть бесплатный тариф Basic, платные начинаются от $6,99 в месяц (на октябрь 2026). Актуально: [Актуальное сейчас](https://aimayak.com/ru/now/).

🎨 **Образ:** Kling — оператор-документалист. Снимает движение как живое, не поставленное.

**Как подключить API:** вход в Kling API идёт по JWT: токен на основе Access Key и Secret Key, он живёт 30 минут. Адрес API и имена моделей меняются между версиями, поэтому в уроке они не зафиксированы: бери актуальные в документации Kling.

```python
import time
import jwt  # pip install pyjwt


def kling_token(access_key: str, secret_key: str) -> str:
    """Токен для Kling API: JWT (HS256), подписанный Secret Key, живёт 30 минут."""
    now = int(time.time())
    payload = {"iss": access_key, "exp": now + 1800, "nbf": now - 5}
    return jwt.encode(payload, secret_key, algorithm="HS256")
```

Токен передаётся в заголовке `Authorization: Bearer <токен>`. Дальше — запрос на создание задачи и опрос статуса по схеме из документации Kling: тот же цикл «отправил задачу → подождал → скачал ролик», что и в примере с Runway.

### Luma — кинематографичная картинка и контроль кадра

Luma AI делает видеомодели Ray (на октябрь 2026 — Ray 3.2: кинематографичное качество и покадровое управление направлением) и Creative Agent, который создаёт и дорабатывает видео, изображения, аудио и текст с учётом стиля бренда. Есть API. Попробовать можно бесплатно в приложении app.lumalabs.ai.

**Что отличает:**

- Покадровое управление: задаёшь первый и последний кадр → AI строит историю между ними
- Loop-видео: бесконечные петли для фонов на сайтах (проверь, поддерживает ли их текущая модель)
- Creative Agent, который держит стиль бренда

**Слабые места:** лица и люди — сверяй на своих промптах. Для продуктов, интерьеров, природы, архитектуры пробуй в первую очередь.

**Цены:** есть бесплатный старт, платные тарифы описаны на сайте.

**Коммерческая лицензия:** смотри условия тарифа на сайте перед сдачей работы клиенту.

### Workflow: Claude как сценарист + Kling/Runway как оператор

🎨 **Образ:** Сборочная линия Ford. Каждый этап делает одно, делает быстро, передаёт дальше. Ты — инженер, который настроил линию, а не рабочий у конвейера.

```
Задача клиента
      ↓
Claude (сценарист) — разбивает на 5–8 сцен
      ↓
Claude — пишет промпт для каждой сцены (EN, операторский язык)
      ↓
Kling / Runway API — параллельная генерация клипов
      ↓
FFmpeg — склеивает клипы в один ролик
      ↓
ElevenLabs — добавляет голосовой комментарий (опционально)
      ↓
Финальный 30-секундный промо-ролик
```

**Полный Python-пайплайн:**

```python
import anthropic
import requests
import subprocess
import json
import os
from pathlib import Path
from runwayml import RunwayML, TaskFailedError  # pip install runwayml

claude = anthropic.Anthropic(api_key=os.environ["ANTHROPIC_API_KEY"])
runway = RunwayML()  # ключ из переменной окружения RUNWAYML_API_SECRET


def create_video_scenes(business_info: str) -> list[dict]:
    """Claude создаёт сценарий: тема + промпты для каждой сцены."""
    response = claude.messages.create(
        model="claude-sonnet-5-5",  # актуальные идентификаторы моделей: документация Anthropic
        max_tokens=2000,
        messages=[{
            "role": "user",
            "content": f"""
Создай сценарий рекламного видео (30 секунд) для этого бизнеса:

{business_info}

Верни JSON: список из 6 объектов:
{{
  "scene_number": 1,
  "duration": 5,
  "description_ru": "Что показываем (для понимания)",
  "video_prompt": "Детальный prompt на английском для платформы видеогенерации. Укажи:
                   тип съёмки (close-up / wide shot / aerial),
                   движение камеры (dolly in / pan right / static),
                   освещение (golden hour / soft natural / studio),
                   атмосферу (warm and inviting / professional / energetic).
                   Минимум 40 слов."
}}

Верни только JSON-массив, без других слов.
"""
        }]
    )
    return json.loads(response.content[0].text)


def generate_clip(prompt: str, duration: int = 5) -> str:
    """
    Генерирует клип через Runway API и возвращает URL видео.
    Чтобы использовать Kling, замени тело функции по документации Kling API:
    остальной пайплайн не изменится.
    """
    try:
        task = runway.text_to_video.create(
            model="gen4.5",
            prompt_text=prompt,
            ratio="1280:720",
            duration=duration,
        ).wait_for_task_output()
    except TaskFailedError as error:
        raise RuntimeError(f"Runway: ошибка генерации: {error.task_details}")
    return task.output[0]


def download_video(url: str, path: str) -> str:
    """Скачивает видео по URL."""
    r = requests.get(url, stream=True)
    r.raise_for_status()
    with open(path, "wb") as f:
        for chunk in r.iter_content(chunk_size=8192):
            f.write(chunk)
    return path


def concat_with_ffmpeg(video_files: list[str], output: str) -> str:
    """FFmpeg склеивает клипы в один ролик."""
    list_path = "/tmp/ffmpeg_list.txt"
    with open(list_path, "w") as f:
        for vf in video_files:
            f.write(f"file '{os.path.abspath(vf)}'\n")

    subprocess.run([
        "ffmpeg", "-y", "-f", "concat", "-safe", "0",
        "-i", list_path, "-c", "copy", output
    ], check=True, capture_output=True)
    return output


def create_promo_video(business_info: str, output_dir: str = "/tmp/promo") -> str:
    """
    Полный пайплайн: бизнес-описание → промо-ролик.
    """
    Path(output_dir).mkdir(parents=True, exist_ok=True)

    print("Claude создаёт сценарий...")
    scenes = create_video_scenes(business_info)
    print(f"Готово: {len(scenes)} сцен")

    clip_files = []
    for scene in scenes:
        n = scene["scene_number"]
        print(f"Генерирую сцену {n}/{len(scenes)}: {scene['description_ru']}")

        try:
            video_url = generate_clip(
                scene["video_prompt"],
                scene.get("duration", 5)
            )
            clip_path = f"{output_dir}/scene_{n:02d}.mp4"
            download_video(video_url, clip_path)
            clip_files.append(clip_path)
            print(f"  ✅ Сцена {n} готова")
        except Exception as e:
            print(f"  ❌ Сцена {n} не удалась: {e}")

    if not clip_files:
        raise RuntimeError("Не удалось создать ни одного клипа")

    final_path = f"{output_dir}/promo_final.mp4"
    concat_with_ffmpeg(clip_files, final_path)
    print(f"\n🎬 Финальный ролик: {final_path}")
    return final_path


# Запуск
if __name__ == "__main__":
    business = """
    Агентство недвижимости "Acme Realty" в Куэнке, Эквадор (условный пример для урока).
    Специализация: продажа квартир русскоязычным покупателям.
    Атмосфера: профессиональная, доверительная, тёплая.
    УТП: русскоязычный сервис.
    Ключевые объекты: квартиры в историческом центре.
    """
    create_promo_video(business)
```

### Коммерческие ограничения и лицензии

Условия лицензий разные и меняются. Общая картина на октябрь 2026:

- **Платные тарифы** обычно разрешают коммерческое использование (по данным страницы тарифов Runway это так)
- **Бесплатные тарифы** обычно ограничивают коммерцию или ставят водяной знак
- Права на результат, ограничения по лицам реальных людей и чужим брендам смотри в условиях сервиса

**Главное правило:** перед сдачей работы клиенту проверь условия именно твоего тарифа на странице сервиса и сохрани скриншот условий. Не обещай клиенту больше, чем разрешает лицензия.

### Себестоимость: считаем свои расходы

Цен для клиента здесь нет: они зависят от рынка, ниши и страны, и доход никто не гарантирует. Считаем только то, что стоит тебе:

- **Кредиты платформы:** число клипов × секунды × расход кредитов за секунду × цена кредита по твоему тарифу (у Runway Gen-4.5 расход 12 кредитов за секунду видео, на октябрь 2026)
- **Голос и монтаж:** ElevenLabs, CapCut и другие по их тарифам
- **Твоё время:** сценарий, проверка каждого клипа, правки

Из этих строк собирается цена услуги: [Как назначить цену](d02-pricing-simple.md), [Сколько стоит клиент и сколько он приносит](d01-unit-economics-simple.md). Типичные форматы: короткие ролики для соцсетей, ежемесячный пакет роликов, видеотур по объекту.

🎨 **Образ:** Ты продаёшь ролик, а не часы. Клиенту всё равно, сделал ты его за 2 часа или 2 дня. Ему нужен результат, который продаёт.

## Практика

### Шаг 1: Заведи аккаунты и ключи (5 мин)

1. Перейди на [kling.ai](https://kling.ai) — международная версия платформы, есть бесплатный тариф Basic

### Шаг 2: Первое видео вручную (10 мин)

Зайди в Kling → Text to Video. Протестируй этот промпт:

```
A modern apartment interior in South America. Cuenca, Ecuador.
Warm golden hour sunlight streaming through large windows.
Slow cinematic dolly shot revealing open living room with mountain views.
Contemporary design, plants, wooden floors, white walls.
Real estate advertisement quality. Professional photography style.
```

Посмотри результат. Попробуй заменить 2–3 слова и сравни — почувствуй как промпт влияет на картинку.

### Шаг 3: Автоматизация через API (10 мин)

Установи зависимости:

```bash
pip install anthropic requests runwayml
```

Запусти скрипт `create_promo_video()` с описанием реального бизнеса из твоего города. Наблюдай как Claude пишет сценарий → Runway генерирует сцены → FFmpeg склеивает финальный ролик.

### Шаг 4: Сравни инструменты (5 мин)

Отправь один и тот же промпт в Runway, Kling и Luma. Сравни:

- Качество изображения
- Реалистичность движения
- Общее время ожидания

Запиши для себя: какой инструмент лучше для каких задач. Это станет основой твоего предложения клиентам.

### Шаг 5: Подготовь пример работы для малого бизнеса (5 мин)

Найди в своём городе малый бизнес без видеоконтента (ресторан, агентство, салон). Подготовь:

- Демо-ролик 15 секунд под их нишу
- Короткое описание: что именно ты делаешь и чего не обещаешь (например, не гарантируешь рост продаж)

Цену и условия считай по урокам про цену и юнит-экономику (ссылки выше). Это портфолио, а не обещание дохода.

- **[Runway](https://runway.com)** — сильный API, профессиональный контроль
- **[Kling AI](https://kling.ai)** — движение людей, звук с липсинком
- **[Luma](https://lumalabs.ai)** — видеомодели Ray, покадровое управление
- **[Google Flow](https://flow.google.com)** — видео от Google, есть бесплатные кредиты в день
- **[Pika](https://pika.art)** — набор приложений для стилизации и эффектов, бесплатный уровень
- **[FFmpeg](https://ffmpeg.org)** — склейка и обработка видео в CLI, бесплатно
- **[CapCut](https://www.capcut.com)** — финальный монтаж с субтитрами и музыкой
- **[ElevenLabs](https://elevenlabs.io)** — голосовой комментарий
- **Цены и версии:** [Актуальное сейчас](https://aimayak.com/ru/now/)

## Ключевые выводы

> Клиенту безразлично, как ты сделал ролик: за 2 часа с AI или за 2 дня с видеографом. Ему нужен ролик, который решает его задачу. AI-инструменты ускоряют производство, но проверка каждого клипа остаётся за тобой.

> API платформы — разница между ручной работой и конвейером. Руками видео делаешь по одному, конвейер запускает серию сцен, пока ты занят другим.

> Платформы быстро меняются: Sora закрыли, у Runway и Kling вышли новые поколения. Строй конвейер так, чтобы платформу можно было заменить одной функцией.
