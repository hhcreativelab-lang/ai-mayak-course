## Ключевые концепции

**LLM** (эл-эл-эм, Large Language Model — большая языковая модель) — AI-система обученная на огромном массиве текста. Она умеет понимать язык и генерировать (создавать) ответы.

**Benchmark** (бенчмарк — тест производительности) — стандартизированный тест для сравнения моделей. Как ЕГЭ для AI: MMLU (эм-эм-эл-ю), HumanEval (хьюман-эвал), MATH (мат), GSM8K (джи-эс-эм-эйт-кей).

**Context window** (контекстное окно) — максимальный объём текста который AI видит и помнит за один раз. Грубо: если окно 200K токенов — модель может держать в памяти книгу на 150 000 слов.

**Token** (токен — минимальная единица текста для AI) — примерно 0.75 слова. "Привет" = 1 токен, "Привет мир" = 2 токена. Каждый токен стоит денег при работе через API (эй-пи-ай, Application Programming Interface — интерфейс программирования, канал связи с моделью).

**Open source / open weights** (опен-сорс — открытый исходный код; опен-вейтс — открытые веса) — модель, чьи веса опубликованы: её можно скачать и запустить у себя. Условия лицензии у разных моделей разные.

**Multimodal** (мультимодальный — работает с несколькими типами данных) — модель умеющая работать не только с текстом, но и с изображениями, звуком, видео.

**Inference** (инференс — вывод) — момент когда модель генерирует ответ на твой вопрос. Провайдер тратит вычислительные ресурсы, ты платишь за токены.

**Parameters** (параметры, или "веса" модели) — числа внутри нейросети. Чем больше — тем умнее модель, но и тяжелее для запуска. Измеряется в миллиардах: 8B, 70B, 405B.

## Теория

### 1. Зачем вообще сравнивать модели?

Многие начинают работу с AI так: узнали про ChatGPT (чат-джипити) — пользуются только им. Или открыли Claude (Клод) — и больше ничего не изучают. Это ошибка того же рода что пользоваться только отвёрткой, отказавшись от молотка, потому что отвёртка попалась первой.

Три причины знать весь рынок:

**Разные задачи — разные сильные стороны.** Обработка огромного юридического документа на 500 страниц — модель с большим контекстным окном (на октябрь 2026 окно в 1 млн токенов у Claude Fable 5.1, Opus 5.5 и Sonnet 5.5, а также у ряда моделей Gemini). Генерация качественного кода — Claude и другие агенты для программирования. Работа с изображениями и голосом в одном запросе — ChatGPT (ЧатДжиПиТи) или Gemini (Джемини). Полная приватность без облака — открытая модель, запущенная у тебя локально.

**Цены отличаются в 10-100 раз.** На октябрь 2026 миллион входных токенов у GPT-6 Luna стоит $0.10, а у GPT-6 Astra — $10. Среди моделей Claude миллион входных токенов стоит от $1 у Haiku 4.5 до $10 у Fable 5.1. Для рутинных задач разница в бюджете огромная.

**Рынок меняется быстро.** Модель которая была лучшей полгода назад могла уступить место новому игроку. Понимая ландшафт (общую карту рынка), ты делаешь informed choice (осознанный выбор) — а не просто идёшь за хайпом.

🎨 Образ: знание всего рынка AI-моделей — как карта города. Ты можешь ездить только по одному маршруту. Но карта показывает: вот объезд когда пробка, вот дорога для грузовика, вот велодорожка.

Anthropic основали в 2021 году бывшие сотрудники OpenAI, включая Дарио Амодеи (Dario Amodei) и Даниэлу Амодеи (Daniela Amodei). Компания сфокусирована на AI safety (безопасности AI) — это один из её главных принципов.

| Claude Sonnet 5.5 (Соннет) | Быстрая | Высокая | $2 / $10 | Повседневные задачи, правки, документы, таблицы |
| Claude Opus 5.5 | Средняя | Очень высокая | $4 / $20 | Основная сильная модель: длинная работа с кодом и документами, по умолчанию в Claude Code |

Актуальные цены и список моделей — на странице [Актуальное сейчас](https://aimayak.com/ru/now/). Есть и модель только по приглашению (Mythos 5.1, проект Glasswing), обычному пользователю она недоступна.

**Context window:** на октябрь 2026 у Fable 5.1, Opus 5.5 и Sonnet 5.5 — 1 миллион токенов (около 555 000 слов, то есть примерно трилогия "Властелин Колец" и ещё немного), у Haiku 4.5 — 200K токенов.

**Сильные стороны Claude:**

- Следование инструкциям — Claude точно выполняет сложные многошаговые задачи не отклоняясь от условий
- Код — одна из сильнейших сторон; сверяйся с актуальными независимыми бенчмарками (например, SWE-bench), рейтинги меняются каждые несколько месяцев
- Длинные документы — анализирует, обобщает, находит противоречия в контрактах и отчётах
- Честность — Anthropic делает на ней упор: модель старается признавать, что чего-то не знает, но галлюцинации (выдуманные факты) всё равно бывают, проверяй важное
- Constitutional AI (конституционный AI) — подход Anthropic к безопасности. Модель обучена по "конституции" из принципов, а не только по человеческой обратной связи

**Слабые стороны:**

- Без поиска и подключённых инструментов нет real-time (реального времени) данных — у модели есть дата, после которой она ничего не знает (в чате доступен веб-поиск)
- Генерация изображений — не основная сильная сторона Claude: для картинок обычно берут отдельные сервисы, например ChatGPT Images или Nano Banana в Gemini
- Мультимодальность ограничена — в API на входе текст и изображения, аудио и видео напрямую не обрабатываются

**Claude Code** — специализированный инструмент для разработчиков от Anthropic. Именно он в центре этого курса. Это не просто Claude в браузере — это агент который умеет читать файлы, писать код, запускать команды в терминале (terminal — консоль операционной системы), управлять проектами. Входит в платные тарифы (Pro и выше).

🎨 Образ: Claude как очень умный, вдумчивый старший коллега. Не торопится, думает перед ответом, признаёт когда чего-то не знает. Редко ошибается, но иногда медленнее чем хотелось бы.

Такой режим «думает вслух» перед ответом, тратит больше времени и точнее на сложных логических задачах, а на простых вопросах избыточен и дороже.

**Экосистема (ecosystem) OpenAI:**

- Work — режим агента для долгих задач (документы, таблицы, презентации), делит лимиты с Codex
- Codex — продукт для разработки: фоновые агенты, проверка изменений
- Генерация изображений встроена в ChatGPT (модель gpt-image-2); DALL-E 2 и 3 отключены в API 12.05.2026
- Whisper (вискер) — speech-to-text (речь в текст) с открытым кодом
- Закрыто: приложение Sora (26.04.2026), Sora API (24.09.2026), Assistants API (26.08.2026)

**Browsing (браузинг):** ChatGPT умеет искать в интернете — для свежих данных это удобно.

**Сильные стороны ChatGPT:**
- Широкая экосистема функций и интеграций
- Встроенная генерация изображений — без отдельного сервиса
- Голос нативно — реальные голосовые разговоры
- Поиск в интернете в самом чате
- Огромная пользовательская база — много туториалов (обучающих материалов), кейсов, сообщества

**Слабые стороны:**
- Набор функций зависит от тарифа и региона, названия моделей часто меняются
- Старшие модели стоят заметно дороже лёгких (разница до 100 раз по API)
- Режим рассуждения медленнее — приходится ждать

🎨 Образ: ChatGPT как смартфон флагман с тысячью приложений. Делает всё, у него огромная экосистема — но конкретный специализированный инструмент иногда бьёт его в своей нише.

- Доступ к Google Search

- Меньше экосистема партнёрских интеграций чем у OpenAI
- Названия продуктов и тарифов меняются часто, актуальные условия нужно проверять

🎨 Образ: Gemini как сотрудник Google — знает все продукты компании наизусть, работает с файлами любого формата, может смотреть видео и слушать аудио. Но вне Google-экосистемы иногда менее гибкий чем конкуренты.

### 6. Открытые модели: Llama (Meta) и другие

Meta — компания которой принадлежат Facebook (Фейсбук), Instagram (Инстаграм), WhatsApp (ВотсАпп). В 2023-2024 они сделали принципиальное решение: выпустить модели Llama с открытыми весами. Это изменило весь рынок.

**Почему Meta выпускала открытые модели?**

Их бизнес-логика: больше разработчиков используют Llama → больше специалистов знают их технологию → Meta лучше привлекает таланты. Плюс они хотели чтобы открытые модели стали стандартом индустрии — это ослабляет позиции OpenAI и Anthropic.

**Важное обновление 2026 года.** В апреле 2026 Meta представила закрытую модель Muse Spark, и ассистент Meta AI теперь работает на ней, а не на Llama. Ранее выпущенные модели Llama остаются доступными для скачивания, но основной упор Meta сместился на закрытую линейку. Открытые веса сегодня выпускают и другие: DeepSeek (V4 под лицензией MIT), Alibaba (часть моделей Qwen), Mistral (часть моделей). Принципы ниже верны для любой открытой модели, а в таблице Llama служит примером по размерам.

**Примеры размеров (семейство Llama 3.x):**

| Модель | Параметры | RAM (оперативная память) | Качество |
|--------|-----------|--------------------------|---------|
| Llama 3.1 8B | 8 млрд | 6-8 GB | Хорошее для размера |
| Llama 3.3 70B | 70 млрд | 40-48 GB | Очень высокое |
| Llama 3.1 405B | 405 млрд | ~250 GB | Близко к лучшим моделям своего времени |

**Что значит "open weights":**
- Скачиваешь веса (числовые параметры) модели — это большой файл, от 4 GB до 240+ GB
- Запускаешь локально через специальный software (программное обеспечение)
- Твои данные никуда не уходят — всё на твоём компьютере
- Можно fine-tune (файн-тюн — дообучить) модель на своих данных
- Сама модель бесплатна, но у лицензии могут быть ограничения: читай условия

**Ollama** (Олама) — один из самых популярных инструментов для запуска открытых моделей. Для личного использования бесплатен. Работает на Mac, Windows, Linux. Установка занимает 5 минут.

**Когда выбирать открытую модель (например, Llama или другую):**

- Данные которые нельзя передавать в облако (медицинские записи, юридические документы, финансы клиентов)
- Хочешь нулевых затрат на API при большом объёме задач
- Хочешь дообучить модель на специфичных данных (например на документах твоей компании)
- Нужна offline работа (оффлайн — без интернета)

**Сильные стороны открытых моделей:**
- Бесплатно при самостоятельном запуске
- Полная приватность — данные не покидают твой компьютер
- Возможность fine-tuning (дообучения)
- Нет зависимости от внешнего API

**Слабые стороны:**
- Нужен мощный компьютер: хотя бы 16 GB RAM для Llama 8B, 64+ GB для 70B
- Качество модели, которую можно запустить на домашнем компьютере, обычно уступает топовым закрытым моделям в точных задачах
- Нет мультимодальности в базовых версиях
- Требует технической настройки

🎨 Образ: открытая модель как Linux — бесплатно, мощно, полный контроль, но требует технических знаний. Claude, ChatGPT, Gemini как macOS — платишь за удобство, скорость и качество "из коробки".

### 7. Mistral (Mistral AI) — европейская альтернатива

Mistral AI основана в 2023 году во Франции тремя исследователями из Google DeepMind и Meta AI. Компания получила одно из крупнейших в Европе первых раундов финансирования — €105 млн.

**Что есть у Mistral на октябрь 2026:**

- **Mistral Vibe** (раньше Le Chat; переименование 12.08.2026, адрес и аккаунт прежние) — ассистент с тремя режимами: Vibe Chat (обычный чат), Vibe Work (исследования, документы, письма) и Vibe Code (код). Тарифы: Free, Pro ($14.99 в месяц), Team ($24.99 за пользователя), цены на октябрь 2026.
- **Модели через API** для разработчиков, часть из них с открытыми весами. Какие именно модели работают внутри Vibe, Mistral на страницах тарифов не называет; список моделей и лицензий смотри на сайте компании.
- Исторически известны модели Mistral Large, Mixtral и Codestral (специализация на коде).

**Mixture of Experts** (микстюр оф эксперт — смесь экспертов): архитектура, которую Mistral популяризовала моделью Mixtral 8x7B. Вместо одной большой нейросети — несколько специализированных "экспертов". На каждый запрос активируется только часть из них (в Mixtral — 2 из 8). Результат: качество большой модели при расходе ресурсов маленькой. Эту идею сегодня используют многие разработчики моделей.

**Почему Mistral важен:**

**GDPR compliance** (джи-ди-пи-ар — General Data Protection Regulation, Общий регламент защиты данных ЕС): регламент ограничивает передачу персональных данных за пределы ЕС без должных гарантий. Mistral как французская компания поддерживает размещение данных в ЕС, поэтому для работы с европейскими корпорациями с ней часто проще пройти проверку. Но "GDPR-friendly" не значит "безопасно по умолчанию": читай условия обработки данных. Например, на бесплатном тарифе Vibe данные по умолчанию идут в обучение моделей, это отключается в настройках приватности.

**Сильные стороны Mistral:**
- Эффективная архитектура — хорошее качество при относительно низкой цене
- Европейский data compliance — GDPR, DORA (ДОР-а, Digital Operational Resilience Act — законодательство ЕС для финансового сектора)
- Часть моделей с открытыми весами — можно запускать локально
- Сильная мультиязычность — особенно европейские языки
- Есть решения для кода (режим Vibe Code) — альтернатива для dev-задач

**Слабые стороны:**
- Меньшая экосистема интеграций чем у OpenAI или Anthropic
- На сложных аналитических задачах флагманы Mistral обычно не лидируют в рейтингах: проверяй на своих примерах
- Меньше публичных бенчмарков и кейсов

🎨 Образ: Mistral как Airbus — европейский вариант рядом с американскими производителями. Технически сопоставим, решает проблему регуляторных требований внутри Европы.

### 10. Практическое дерево решений — когда что выбирать

Используй эту схему когда встаёт вопрос "какую модель взять для задачи":

```
ЗАДАЧА → УСЛОВИЕ → ПОДХОДЯЩИЙ ВЫБОР (на октябрь 2026)

Пишу код / разрабатываю систему → приоритет точности инструкций
  → Claude (Sonnet 5.5 или Opus 5.5) + Claude Code

Анализирую очень длинный документ (>100 страниц, книга, кодовая база)
  → модель с окном в 1M токенов: Claude Sonnet / Opus / Fable или Gemini

Работаю с изображениями + голосом + видео в одном запросе
  → ChatGPT или Gemini

Данные нельзя передавать в облако (медицина, юридика, финансы клиентов)
  → открытая модель (Llama, DeepSeek, Qwen, Mistral) локально через Ollama

Нужна скорость + минимальная стоимость для рутинных задач
  → Claude Haiku 4.5, быстрые модели Gemini Flash или GPT-6 Luna

Компания работает в ЕС, строгий GDPR
  → Mistral (проверь условия обработки данных) или любой сервис с размещением в ЕС

Сложная математика / логика / алгоритмические задачи
  → режим рассуждения у Claude, ChatGPT или Gemini Deep Think

Начинаю с нуля, хочу попробовать бесплатно
  → claude.ai (бесплатный тариф) или chatgpt.com (бесплатно)

Хочу local AI (локальный AI) без зависимости от интернета
  → Ollama + любая открытая модель по размеру твоего компьютера

Работаю с данными X/Twitter, нужен real-time
  → Grok

Анализирую китайский рынок / работаю с китайским языком
  → Qwen или DeepSeek
```

### 11. Важная деталь: цены меняются быстро

За последние годы стоимость AI API для моделей одного и того же уровня качества заметно снизилась. Причины:

- Конкуренция между компаниями
- Улучшение эффективности (efficiency — КПД) чипов и алгоритмов
- Открытые модели давят на цены закрытых

Следствие: не запоминай конкретные цифры — они устареют. Запомни принцип: всегда проверяй актуальные цены перед запуском проекта на странице [Актуальное сейчас](https://aimayak.com/ru/now/) и на сайтах поставщиков: Anthropic (claude.com/pricing), OpenAI, Google AI Studio.

### 12. Почему этот курс выбрал Claude Code

Мы изучаем Claude Code — и это сознательный выбор, а не фанатизм.

**Причина 1: Качество кода.** Claude входит в число сильнейших моделей для программирования. Проверяй актуальные независимые бенчмарки (SWE-bench — тест на решение реальных GitHub issues), рейтинги меняются с каждым релизом.

**Причина 2: Большой context window.** До 1M токенов (на октябрь 2026) позволяют загрузить весь проект в контекст и работать с ним как с единым целым. Это критично для разработки реальных систем.

**Причина 3: Claude Code как специализированный инструмент.** Это не просто чат с API — это агент с интеграцией в терминал, файловую систему, git (джит — система контроля версий). У других компаний есть свои агенты для программирования (например, Codex у OpenAI, Cursor, Devin Desktop), идеи курса переносятся на них; Claude Code выбран потому, что на нём удобно показывать практику.

**Причина 4: Следование инструкциям.** Для работы с complex workflows (сложными рабочими процессами) — агентами, хуками, скиллами — нужна модель которая точно выполняет многошаговые инструкции без отклонений. Claude с этим хорошо справляется.

**Что это НЕ значит:**

- Claude не лучший для всех задач — ты уже видел это в таблице и дереве решений
- В реальной профессиональной работе ты будешь использовать несколько моделей
- Multi-model стратегия (стратегия нескольких моделей) — норма для серьёзных проектов: Claude для кода, Gemini для видео и Google-среды, ChatGPT для голоса и изображений, открытая модель для приватных данных

Понимать весь ландшафт — и при этом хорошо знать один инструмент — вот правильный подход.
