# Pricing & Access Levels — Free / Pro / Max / Team / API: что покупать когда

**Модуль:** 2. Быстрый старт | **Время:** ~25 мин теории + 10 мин на выбор тарифа

---

## Суть урока

Anthropic имеет **5 уровней доступа к Claude** (плюс отдельно API). Каждый уровень — это свой набор фич, своя цена и свои лимиты. Не выбрал правильный — либо переплачиваешь, либо упираешься в потолок каждые два часа.

Главное что нужно понять с самого начала: **на бесплатном аккаунте Claude Code не работает**. Бесплатный аккаунт даёт чат на claude.ai, в приложении и на телефоне. Для терминала или VS Code нужен платный тариф (Pro минимум) или API-ключ с оплатой по токенам.

Этот урок — карта на октябрь 2026. Цены и лимиты меняются, поэтому актуальные значения всегда смотри на странице [Актуальное сейчас](https://aimayak.com/ru/now/) и на официальной странице тарифов. Кто что получает за свои деньги, кому какой тариф нужен, и как оплачивать из разных стран.

🎨 **Образ:** AI-доступ как мобильный тариф. Free — "пакет на всякий случай позвонить маме". Pro — рабочий тариф для каждого дня. Max — корпоративный безлимит. Team — групповой семейный план. API — почасовая оплата таксисту, платишь за каждую секунду. Enterprise — частный самолёт с пилотом по контракту.

## 🎯 Decision tree: какой tier мне нужен

Главный вопрос — не "какой тариф самый крутой", а "сколько часов в день я реально буду работать с Claude".

```
Хочу попробовать AI первый раз
  → Free ($0)

Использую каждый день 1-3 часа, нужен Claude Code в терминале
  → Pro ($20/мес monthly, или $17/мес при годовой = $200/год)

Использую 6-8 часов в день (developer / builder)
  → Max 5x (от $100/мес)

Использую 8+ часов в день intensive (full-time на Claude Code)
  → Max 20x ($200/мес)

У меня команда 5+ человек, нужны shared projects
  → Team Standard ($25/seat monthly, $20/seat annual)
  → Team Premium ($125/seat monthly, $100/seat annual — 5x от Standard)

Регулируемая отрасль (healthcare/finance) или 100+ пользователей
  → Enterprise ($20/seat + API usage, sales call)

Строю программу/бота/Worker который вызывает Claude из кода
  → API (отдельная подписка, не Pro/Max)
```

**По умолчанию для русскоязычного builder'а:** Pro (\$20). Для большинства задач этого хватает. Перейдёшь на Max когда реально упрёшься в лимит несколько раз в неделю.

🎨 **Образ:** велосипед vs внедорожник. До магазина в 2 км — велосипед. Через бездорожье — внедорожник. Не покупай Land Cruiser чтобы съездить за хлебом.

## Ключевые концепции

- **Tier** — уровень подписки на Claude. Определяет какие модели доступны, лимит сообщений, и какие фичи открыты
- **Conversation limit** — сколько диалогов с Claude ты можешь провести в сутки. Считается не сообщениями, а conversations (один длинный чат = одна conversation)
- **Claude Code** — агент для программирования: терминал, VS Code, приложение, браузер. Требует платный тариф (Pro, Max, Team, Enterprise) либо API ключ
- **Fable / Opus / Sonnet / Haiku** — четыре семейства моделей. Haiku быстрый и дешёвый, Sonnet баланс, Opus умнее и стоит по умолчанию на подписках, Fable самая сильная и дорогая
- **Token** — единица текста. Примерно 4 символа или 0.75 слова английского текста; у русского текста токенов на то же число слов больше. Английский текст из 1500 слов ≈ 2000 токенов
- **Prompt caching** — Anthropic кэширует повторяющийся контекст: чтение из кэша стоит 10% от цены входа (у части моделей ещё меньше)
- **Batch API** — асинхронный режим. Отправляешь запросы, Claude обрабатывает в течение 24 часов, ты получаешь 50% скидку
- **Computer Use** — функция в режиме research preview, где Claude управляет твоим компьютером (двигает курсор, печатает). В приложении доступна на Pro и Max
- **Console** — отдельный личный кабинет на platform.claude.com (раньше console.claude.com) где управляешь API ключами и оплатой API (не Pro/Max)

## Теория

### Tier 1: Claude Free (\$0/мес)

**Что доступно:**

- claude.ai в браузере, приложение на компьютере и на телефоне
- Небольшой лимит сообщений, зависит от нагрузки (точное число не фиксировано)
- Модели Sonnet и Haiku (Opus на Free не входит)
- Артефакты (Artifacts), навыки (Skills), поиск в интернете, создание файлов, память
- Projects — до 5
- **НЕТ Claude Code**
- API — отдельный аккаунт в Console, к Free не относится

**Для кого:**

- Школьник / студент тестирует AI первый раз
- Журналист пишет одну статью в неделю с помощью AI
- Любой кто хочет понять "а оно вообще как работает" перед покупкой

**Когда переходить выше:**

- Упираешься в дневной лимит и хочешь продолжить
- Понял что хочешь работать в терминале / VS Code
- Нужно больше пяти Projects или больше использования

**Ссылка:** [claude.ai](https://claude.ai) — регистрация бесплатная

🎨 **Образ:** автобус — бесплатно ездит, но в час пик стоишь между потными людьми. На пары нормально, на работу каждый день — нет.

### Tier 2: Claude Pro (\$20/мес monthly или \$17/мес при annual = \$200/год)

Это **базовый рабочий тариф**. С него обычно и начинают.

**Что доступно:**

- Больше использования, чем на Free (по странице тарифов: в 5 раз больше за 5-часовую сессию, плюс недельные лимиты)
- Opus 5.5 (модель по умолчанию в Claude Code), Sonnet 5.5, Haiku 4.5; Fable 5.1 через usage credits
- **Claude Code** в терминале, VS Code, приложении для компьютера и браузере — главное отличие от Free
- Загрузка файлов в чат (PDF, изображения, документы)
- Projects — папки с persistent context (привязал свой codebase, Claude помнит)
- Artifacts — HTML/code preview прямо в чате
- Claude Cowork, Research, Claude Design / Slides / Docs
- Computer Use (research preview, включается через настройки приложения)

**Экономия:** годовая подписка \$200/год = \$17/мес (vs \$20 monthly) — экономия ~15%.

**Лимиты Claude Code:**

- Лимит считается по 5-часовым сессиям и по неделям, точные цифры зависят от модели и нагрузки
- Посмотреть остаток: команда `/usage` в Claude Code или страница Usage в настройках
- Самые мощные модели (Opus, Fable) тратят лимит быстрее, чем Sonnet и Haiku. Fable на подписках идёт через usage credits

**⚠️ Важно про токенизатор:** модели 4.7 и новее (в том числе Opus 5.5, Sonnet 5.5, Fable 5.1) используют новый токенизатор: на тот же текст уходит примерно на 30% больше токенов, чем у Sonnet 4.6 и старше. Лимит ты исчерпаешь быстрее чем кажется по объёму текста.

**Для кого:**

- Разработчик который пишет код 2-4 часа в день
- Контент-маркетолог пишет статьи и посты
- Solo founder управляет проектами
- Любой кто работает 1-3 часа в день с AI

**Когда переходить выше:**

- Упираешься в лимит Opus несколько раз в неделю
- Работаешь в Claude Code 6+ часов в день
- Видишь сообщение "Approaching limit" чаще одного раза в день

**Ссылка:** [claude.com/pricing](https://claude.com/pricing) или [claude.ai/upgrade](https://claude.ai/upgrade)

🎨 **Образ:** обычный седан. Едешь когда хочешь, тариф фиксированный, бензина хватает на ежедневные маршруты. На дальнобой не подходит, но 95% задач решает.

### Tier 3: Claude Max (от \$100/мес — два тира)

Max — для тех кто работает с Claude **много**. Два уровня: 5x и 20x от лимита Pro (цены на октябрь 2026).

#### Max 5x (от \$100/мес)

- 5x от Pro лимита за 5-часовую сессию
- Тот же набор фич что Pro
- Ранний доступ к новым функциям
- Приоритетный доступ в часы высокой нагрузки
- Выше лимиты на вывод

#### Max 20x (\$200/мес)

- 20x от Pro лимита
- Тот же набор фич, что у Max 5x
- Самый высокий лимит использования среди индивидуальных тарифов

**Для кого:**

- Разработчик 6-8 часов в день в Claude Code (Max 5x)
- AI-агентство ведёт 5+ клиентов параллельно (Max 5x или 20x)
- Builder работает 8+ часов intensive (Max 20x)
- Solo founder с большим объёмом контента и кода ежедневно

**Опасность:**

- Легко перейти на Max просто "потому что круто и я могу"
- Без реальных 6+ часов в день — деньги не окупятся
- Max оправдан, когда ты регулярно упираешься в лимит Pro
- Проверь свой реальный usage в Pro перед апгрейдом

**Ссылка:** [claude.com/pricing](https://claude.com/pricing) или [claude.ai/upgrade](https://claude.ai/upgrade) — там же где Pro

🎨 **Образ:** Tesla Plaid. Едет быстро, далеко, когда хочешь куда хочешь. Но если ты ездишь на ней до магазина — это переплата. Купил под реальную задачу — заслужено.

### Tier 4: Claude Team (две градации — Standard и Premium)

Это **командный тариф** для small business. С 2026 года Anthropic разделил Team на два уровня:

#### Team Standard

- **Monthly:** \$25/seat/мес
- **Annual:** \$20/seat/мес — экономия 20%
- Все фичи Claude, SSO, centralized billing

#### Team Premium

- **Monthly:** \$125/seat/мес
- **Annual:** \$100/seat/мес
- **5x больше использования** vs Standard seats
- Расширенные лимиты на тяжёлых моделях

**Что доступно (общее для обоих):**

- Все возможности Pro для каждого пользователя, включая Claude Code
- **Shared projects** — несколько человек работают над одним контекстом
- Centralized billing — один счёт на всю команду
- Admin controls — кто может что
- SSO (Single Sign-On) интеграция
- Team usage analytics — видишь кто сколько потратил
- Workspace separation между членами команды

**Что НЕ даёт Team (это уровень Enterprise):**

- SCIM provisioning и полные audit logs
- Compliance API и кастомные сроки хранения данных
- HIPAA-ready

**Примеры расчёта (Standard, annual):**

- 5 seats = \$100/мес
- 10 seats = \$200/мес
- 50 seats = \$1000/мес

**Для кого:**

- Стартап 5-50 человек (Standard если работа умеренная, Premium если heavy на Opus)
- Маленькое AI-агентство с командой
- Семейный бизнес где 3-5 человек используют AI ежедневно

**Ссылка:** [claude.com/pricing](https://claude.com/pricing)

🎨 **Образ:** корпоративная парковка. Все паркуются, шлагбаум один, счёт общий. Удобно, но для большой компании уже мало (там Enterprise со своей парковкой).

### Tier 5: Claude Enterprise (custom pricing)

**Что доступно:**

- SCIM provisioning
- Полные audit logs
- HIPAA-ready (для healthcare)
- DPA (Data Processing Agreement) для GDPR
- IP allowlisting
- Claude Security (beta)
- Advanced SSO + admin controls
- Custom rate limits и model access
- Dedicated support manager

**Цена (на октябрь 2026):**

- **\$20/seat в месяц при оплате за год + API usage** — гибрид «место + потребление»
- API usage оплачивается отдельно, по официальным тарифам моделей
- Annual contracts типичны
- Финальная цена обсуждается с sales team

**Для кого:**

- Компании 100+ человек
- Регулируемые отрасли (healthcare, finance, legal)
- Enterprise SaaS которые встраивают Claude в свой продукт
- Государственные / quasi-government контракты

**Как купить:** через команду продаж Anthropic (Contact Sales), а не через сайт самообслуживания

**Ссылка:** [claude.com/pricing](https://claude.com/pricing) → Contact Sales

🎨 **Образ:** частный самолёт с экипажем. Дорого, кастомизация полная, для специфических задач. Покупать "на всякий случай" — глупо. Покупать когда реально летаешь раз в неделю в командировки за океан — оправдано.

### Tier 6: Anthropic API (платишь за использование)

API — это **отдельная история**. Это не подписка с месячной оплатой, а pay-as-you-go.

**Что это:**

- Программный доступ к моделям через HTTP requests
- Не chat-интерфейс, а **строительный материал** для своих программ
- Используешь в коде: Python, TypeScript, Go, любой язык
- Платишь за каждый токен который обработан

**Важно:**

- API **НЕ зависит** от Pro/Max подписки. Это отдельный аккаунт
- Можно иметь Pro для chat + API для своих программ одновременно
- API оплачивается через Console, platform.claude.com (отдельный личный кабинет)

**Цены на октябрь 2026** (за миллион токенов, по официальной странице цен Anthropic; актуальные значения всегда на странице [Актуальное сейчас](https://aimayak.com/ru/now/)):

#### Claude (Anthropic)

| Модель | Input | Output | Когда использовать |
|---|---|---|---|
| Haiku 4.5 | \$1.00 | \$5.00 | Простые задачи: классификация, перевод, краткие ответы |
| Sonnet 5.5 | \$2.00 | \$10.00 | Баланс цена/качество для большинства задач, 1M context |
| Opus 5.5 | \$4.00 | \$20.00 | Сложные reasoning, архитектура, deep analysis, 1M context |
| Fable 5.1 | \$10.00 | \$50.00 | Самые долгие и сложные задачи, 1M context |

Цена модели меняется от поколения к поколению: новое поколение Opus может стоить заметно дешевле предыдущего. Поэтому не запоминай цифры, а сверяйся с таблицей перед расчётом.

**⚠️ Токенизатор:** модели 4.7 и новее (в таблице это Opus 5.5, Sonnet 5.5 и Fable 5.1) используют более новый токенизатор: на тот же текст уходит примерно на 30% больше токенов, чем у Sonnet 4.6 и старше. Точное увеличение зависит от текста. Реальный счёт может оказаться выше расчётного, закладывай запас +30% при переносе расчётов со старых моделей.

**Mythos:** Claude Mythos 5.1 доступна только по приглашению (Project Glasswing), обычному пользователю её не получить.

**Вывод моделей из API:** старые модели закрывают. Claude Opus 4, Opus 4.1, Sonnet 4 и Haiku 3.5 уже выведены из Claude API (местами остаются на Amazon Bedrock и Google Cloud). Claude Haiku 4.5 может быть выведен не раньше 15 октября 2026. Если в production стоит устаревшая модель, следи за страницей [model deprecations](https://platform.claude.com/docs/en/about-claude/model-deprecations) и мигрируй заранее.

#### OpenAI (для сравнения, на октябрь 2026)

| Модель | Input | Output | Когда |
|---|---|---|---|
| gpt-6-luna | \$0.10 | \$0.50 | Самый дешёвый и быстрый |
| gpt-6.1-sol | \$2.00 | \$10.00 | Баланс |
| gpt-6-astra | \$10.00 | \$50.00 | Самая сильная |

Названия и цены OpenAI меняются часто, актуальные значения смотри на официальной странице цен API OpenAI.

**Что такое токен на практике:**

- ~4 символа английского текста или ~0.75 слова = 1 токен; русский текст обычно тяжелее: на то же число слов уходит больше токенов
- Для моделей 4.7 и новее закладывай примерно **+30%** из-за нового токенизатора
- Один промпт "напиши пост в Telegram" с context-window 10K input + 2K output ≈ \$0.04 на Sonnet 5.5

**Пример расчёта (Sonnet 5.5):**

- 1000 запросов с 500 input + 500 output (номинальных) токенов
- С запасом +30% на токенизатор: ~650 input + ~650 output
- Input: 650 × 1000 / 1_000_000 × \$2 = \$1.30
- Output: 650 × 1000 / 1_000_000 × \$10 = \$6.50
- Итого: **~\$7.80** за 1000 запросов

**Пример расчёта (Opus 5.5):**

- Те же 1000 запросов, ~650 input + ~650 output с запасом на токенизатор
- Input: 650 × 1000 / 1_000_000 × \$4 = \$2.60
- Output: 650 × 1000 / 1_000_000 × \$20 = \$13.00
- Итого: **~\$15.60** за 1000 запросов (вдвое дороже Sonnet 5.5 на той же задаче)

**Способы сэкономить:**

- **Prompt caching** — чтение из кэша стоит 10% от цены входа (детали ниже и в уроке [Prompt Caching и Batch API](34-prompt-caching-batch-api.md))
- **Batch API** — 50% скидка если ты готов ждать до 24 часов на обработку. Детали в том же уроке
- **Haiku 4.5 вместо Sonnet 5.5** — для простых задач экономия в 2x
- **Меньше output tokens** — генерируй кратко, output дороже input в 5x

#### Prompt Caching — детальная разбивка (на октябрь 2026)

| Операция | Множитель базовой цены | TTL |
|---|---|---|
| Cache write 5 мин | **1.25x** (на 25% дороже первой записи) | 5 минут |
| Cache write 1 час | **2.0x** (вдвое дороже) | 1 час |
| Cache read hit | **0.1x — скидка 90%** (у Opus 5.5 — 0.05x, у Fable 5.1 — 0.025x) | пока кэш живой |

**Примеры на Sonnet 5.5 (\$2/MTok input):**

- Cache write 5 мин: \$2.50/MTok
- Cache write 1 час: \$4.00/MTok
- Cache read hit: \$0.20/MTok

**Логика окупаемости:** cache окупается после 1 чтения (если write 5-мин) или 2 чтений (если write 1-час).

#### Платные инструменты API (на октябрь 2026)

- **Web Search:** \$10 / 1000 поисков (+ стандартные токены)
- **Web Fetch:** бесплатно (только токены)
- **Code Execution:** бесплатно когда вместе с web search/fetch; иначе \$0.05/час/контейнер. 1550 часов/мес бесплатно
- **Managed Agents (Claude Managed Agents):** \$0.08/session-hour — оплата только времени `running`

#### Что нового у Anthropic (на октябрь 2026)

- **Fable 5.1** (1 сентября 2026) — самая сильная из общедоступных моделей
- **Opus 5.5** (22 сентября 2026) и **Sonnet 5.5** (28 сентября 2026) — основные рабочие модели
- **Claude Mythos 5.1** — только по приглашению (Project Glasswing), в общий доступ не вышла
- **1M context окно** — у Fable 5.1, Opus 5.5 и Sonnet 5.5 входит в стандартную цену без наценки; у Haiku 4.5 окно 200K

**Для кого:**

- Разработчик строит Cloudflare Worker / бота / автоматизацию
- SaaS встраивает Claude в свой продукт
- Любая программа которая вызывает Claude из кода >100 раз в день

**Когда переходить с Pro на API:**

- Хочешь автоматизировать обработку (бот, cron, batch processing)
- Нужно интегрировать Claude в собственный продукт
- Объём вызовов превышает то что Pro даёт через chat

**Ссылка:** [platform.claude.com](https://platform.claude.com) (Console) → Billing → Add credit

**Минимальную сумму пополнения и способы оплаты** смотри в Console → Billing.

🎨 **Образ:** такси с почасовой оплатой. Платишь только когда едешь. Удобно если ездишь редко или непредсказуемо. Невыгодно если ездишь каждый день по 8 часов — там подписка Pro/Max дешевле.

### Главные мифы и антипаттерны

**❌ "Куплю Max сразу потому что круто"**

Без реальных 6-8 часов в день работы Max не окупится. Pro уже даёт заметно больше использования, чем Free. Начинай с Pro, апгрейдись когда упираешься в лимит.

**❌ "API дешевле чем Pro для общения с Claude"**

Для интерактивного чата API обычно **дороже** Pro: на каждом ответе в запросе уходит вся история диалога. Пример на Sonnet 5.5 (цены на октябрь 2026): 100 запросов в день по 20K токенов на входе и 1K на выходе = 2M входных × \$2 + 0.1M выходных × \$10 = \$5 в день, то есть около \$150 в месяц. Pro стоит фиксированно \$20 (или \$17 annual).

API дешевле только для **программной автоматизации**: один Worker делает 5K вызовов в день, каждый на 500 токенов на входе и 100 на выходе = 2.5M × \$2 + 0.5M × \$10 = \$10 в день. Через чат ты столько не сделал бы.

**❌ "Pro + API заменяет Team"**

Частично. Pro + API даёт тебе персональный доступ + автоматизацию. Но НЕ даёт:

- Shared projects между членами команды
- Centralized billing
- Admin controls
- Team usage analytics

Если у тебя 3 человека работают вместе — Pro × 3 = \$60 (или \$51 annual). Если 5+ человек — Team Standard логичнее (\$100/мес annual для 5 seats).

**❌ "Free достаточно для всего"**

Для чата — может быть. Для Claude Code — **нет**, его на Free просто нет. Если хочешь писать код в терминале — нужен платный тариф (Pro минимум) или API-ключ.

**❌ "Купил Pro — Claude Code сразу работает"**

Не сразу. Pro даёт **право** на Claude Code, но сам терминал/VS Code + установка Claude Code нужны отдельно. См. урок [Установка и настройка](05-setup.md).

**❌ "Подписку можно поставить на паузу"**

Не рассчитывай на паузу. Проверь в Settings → Billing, какие варианты доступны на твоём тарифе: отмена, смена тарифа или другое. Перед отменой сохрани важные Projects и переписки, а условия хранения данных посмотри в официальной справке.

### Платёжные нюансы и доступ по странам

Anthropic открывает доступ и принимает оплату только в списке поддерживаемых стран: [anthropic.com/supported-countries](https://www.anthropic.com/supported-countries). Список меняется, поэтому перед покупкой сверься с официальной страницей.

**Что проверить:**

- Твоя страна есть в списке поддерживаемых (на октябрь 2026 в списке, например, Эквадор, Испания, Германия, Канада, Турция, Грузия, Армения, Казахстан)
- Карта выпущена банком, который проводит международные онлайн-платежи в долларах

**Россия и Беларусь:** на октябрь 2026 обеих стран в списке поддерживаемых нет. Русский язык Claude при этом понимает везде, где сервис доступен. Если твоей страны нет в списке, не ищи обходные пути: оплата через чужой аккаунт или посредников нарушает условия сервиса, и аккаунт могут заблокировать. Законная альтернатива — локальные модели, которые работают на твоём компьютере без аккаунта: [Локальные модели: Ollama и LM Studio](63-local-models-ollama.md).

**Способы оплаты:**

- Банковская карта — основной способ для подписок и API
- Для Enterprise возможен счёт по договору (invoicing)
- Остальные способы зависят от платформы и страны, смотри в Settings → Billing

**Резервная карта:**

Платёж может не пройти не только из-за страны: бывает сбой антифрода банка или смена IP. Добавь в личный кабинет вторую карту другого банка и следи, чтобы на ней хватало средств.

**Если оплата не прошла:**

1. Не паникуй: сначала проверь причину в Settings → Billing (часто «card declined by issuer» означает звонок в банк)
2. Обнови карту или добавь резервную
3. Если ничего не помогает — напиши в поддержку Anthropic из личного кабинета и приложи данные транзакции

**Возврат денег:** условия возврата зависят от тарифа и региона. Актуальные правила смотри в справке поддержки Anthropic ([support.claude.com](https://support.claude.com)), для Team и Enterprise — в договоре.

**Автопродление:**

- Включено по умолчанию
- Отключить можно в Settings → Billing
- Доступ сохраняется до конца оплаченного периода

### Combining tiers: какие комбинации работают

Часто builder'у нужно несколько тарифов одновременно. Это нормально:

**Pro + API** (самый частый combo для solo developer)

- Pro \$20 (или \$17 annual) для chat и Claude Code
- API на \$20-50/мес для своих Worker'ов и автоматизаций
- Итого \$37-70/мес — хорошо покрывает большинство задач

**Max 5x + API** (для serious builder)

- Max от \$100/мес для intensive работы в Claude Code
- API на \$50-200/мес для production систем
- Итого \$150-300/мес — оправдано, если ты регулярно упираешься в лимит и production-системы реально работают

**Team Standard + API** (для агентства)

- Team Standard annual = \$100/мес для 5 мест (команда может быть от 2 человек)
- API на shared automations \$100-500/мес
- Для агентства с несколькими клиентами — удобная база

**Free + API** (для разработчика-минималиста)

- Free \$0 для случайных запросов
- API для своих программ
- Только если **не нужен** Claude Code в терминале

**Не комбинируется:**

- ❌ Несколько платных подписок на один аккаунт: у аккаунта один тариф, он меняется апгрейдом или даунгрейдом

### Как реально посчитать свой tier

Не угадывай — посмотри на свой usage пару недель.

**Шаг 1: Начни с Pro (\$20)**

Дёшево, есть Claude Code, можно отменить в любой момент.

**Шаг 2: Через 2 недели проверь в Settings → Usage:**

- Сколько раз упёрся в лимит? (0-2 = Pro хватает, 5+ = пора Max)
- Сколько часов в день в Claude Code? (1-3 = Pro, 6+ = Max)
- Использовал ли Opus и упирался ли в его лимит?

**Шаг 3: Решай data-driven:**

- Никаких лимитов не упёрся → остаёшься на Pro
- Упёрся 2-3 раза → попробуй Max 5x на месяц
- Упёрся 10+ раз → Max 20x оправдан
- Хочешь автоматизацию параллельно → добавь API на \$20-50

**Шаг 4: Перепроверяй каждый квартал**

Твоё использование меняется. Иногда лучше downgrade на Pro если работа поменялась.

## Ключевые выводы

> Не выбирай tier "потому что круто". Выбирай под реальное использование. Начинай с Pro (\$20 monthly или \$17 annual = \$200/год), апгрейдись когда реально упрёшься в лимит несколько раз в неделю.

> Цены на модели меняются от поколения к поколению. На октябрь 2026 Opus 5.5 стоит \$4/\$20 за миллион токенов, Sonnet 5.5 — \$2/\$10, а прежние поколения Opus стоили заметно дороже. Модели 4.7 и новее используют новый токенизатор: примерно на 30% больше токенов на тот же текст, закладывай запас в расчёты.

> Старые модели выводятся из API. Если в production стоит устаревшая модель, следи за страницей model deprecations и мигрируй заранее, иначе вызовы начнут падать.

> API и Pro — это **разные вещи**, не путать. Pro даёт тебе чат и Claude Code. API даёт твоей программе доступ к моделям, оплата идёт по токенам отдельно, через Console. Builder обычно нуждается в обоих параллельно.

> Доступ к Claude зависит от страны. На октябрь 2026 Россия и Беларусь не входят в список поддерживаемых стран Anthropic. Не обходи ограничение через чужие аккаунты и посредников: это нарушает условия сервиса. Проверяй список на официальной странице.
