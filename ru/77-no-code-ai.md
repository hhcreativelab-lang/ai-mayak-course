# No-code AI — v0, Webflow AI и Framer для не-программистов

**Время:** ~25 мин теории + 35 мин практики

---

## Суть урока

🎨 **Образ:** Представь архитектора, которому не нужен чертёжник. Ты описываешь словами: «хочу трёхкомнатный дом с панорамными окнами и тёплым гаражом» — и за 30 секунд перед тобой стоит готовый проект. Ты не трогал карандаш, не знаешь СНиПы, но дом выходит профессиональный. Именно так работают no-code AI инструменты: ты описываешь что хочешь — они строят. Claude Code при этом становится прорабом, который подключается когда нужна нестандартная электрика или сантехника, которую типовой проект не предусмотрел.

Этот урок — про то, как собирать сайты и приложения для себя и клиентов, не написав ни строчки кода вручную. И про то, когда no-code достаточно, а когда нужно подключать Claude.

---

## Ключевые концепции

- **No-code AI** (ноу-код AI — разработка без написания кода) — инструменты, которые генерируют интерфейс, контент и логику приложения из текстового описания на человеческом языке
- **v0** (v0.app, раньше v0.dev) — сервис Vercel: по промпту (запросу к AI) собирает интерфейсы и приложения на React; полученный код можно скопировать прямо в Claude Code
- **Webflow AI** — встроенный ИИ в Webflow для генерации текста, изображений и CMS-контента без выхода из редактора
- **Framer AI** — создание лендинга из одного предложения с автоматической адаптацией под мобильные устройства
- **Гибридный подход** — v0 или Framer генерируют визуальную часть, Claude Code добавляет бизнес-логику, интеграции с API (эй-пи-ай — интерфейс программирования) и базой данных
- **Ниша «сборщика»** — услуга: принимать заказы на сайты, быстро собирать их инструментами из этого урока, сдавать клиенту как готовый продукт
- **Сравнение скорости и гибкости** — no-code быстрее для типовых задач, Claude Code незаменим для кастомной логики и долгосрочного масштабирования
- **Lovable и Bolt.new** — конкуренты Claude Code для non-coders: генерируют full-stack приложения из описания, но имеют потолок кастомизации

## Теория

### Почему no-code AI стал профессиональным инструментом

Раньше «сделать сайт без кода» означало Tilda с блоками и ограниченной анимацией. Теперь no-code AI инструменты генерируют Production-ready React-компоненты, настраивают адаптивность, пишут CMS-поля и деплоят на CDN (сеть доставки контента). Разрыв между «сделал сам» и «нанял разработчика» сократился настолько, что предприниматель без технического бэкграунда может быстро собрать простой сайт, на который раньше уходили недели работы команды.

Это создаёт конкретную бизнес-возможность: стать «сборщиком» — человеком, который знает эти инструменты лучше клиента, берёт деньги за экспертизу в выборе стека и скорость сборки, а не за написание кода.

### v0 (Vercel) — текст в интерфейс на React

**Что это.** v0 (адрес v0.app, раньше v0.dev) — сервис от Vercel, создателей Next.js. Теперь это агент, который собирает интерфейсы и full-stack приложения. Ты пишешь промпт («сделай карточку товара с изображением, ценой, кнопкой в корзину и бейджем скидки»), и получаешь готовый React-код с Tailwind CSS и shadcn/ui. Есть бесплатный план; платные тарифы работают на кредитах по расходу токенов (условия на [v0.app/pricing](https://v0.app/pricing)).

**Как работает.** v0 понимает не только «кнопка», но и «кнопка в стиле Stripe с hover-эффектом и loading-состоянием». Выходной код — обычный React/Next.js, который копируется в проект; небольшая доводка под твой проект обычно нужна.

**Killer-фича для гибридного подхода.** Сгенерированный код вставляешь в Claude Code и говоришь: «подключи этот компонент к моему API /products/:id, добавь skeleton-загрузку и обработку ошибок». Claude Code дописывает логику поверх визуала от v0.

**Практический workflow (воркфлоу — рабочий процесс):**

1. Описываешь в v0 нужный экран или компонент
2. Итерируешь промптом («сделай заголовок крупнее», «добавь тёмную тему»)
3. Копируешь финальный код
4. Вставляешь в Claude Code, описываешь бизнес-логику
5. Claude Code интегрирует данные, добавляет валидацию, деплоит

🎨 **Образ:** v0 — это дизайнер, который рисует скетч за 30 секунд. Claude Code — разработчик, который берёт скетч и превращает его в работающий продукт. Ты — менеджер, который ставит задачи обоим.

### Webflow AI — контент и CMS без рутины

**Что это.** Webflow — визуальный редактор для создания сайтов с нативным хостингом. В Webflow есть AI-функции: генерация текста прямо в редакторе, помощь с CMS-контентом, перевод сайта. Состав функций и тарифы меняются, смотри актуальное на сайте Webflow.

**AI в CMS.** Ты создаёшь CMS-коллекцию «Услуги» с полями: название, описание, цена. Включаешь AI-поле для «описания» — и Webflow сам генерирует описание на основе названия и контекста сайта. Для агентства с 50 услугами это экономит дни работы копирайтера.

**Локализация в Webflow.** Встроенный перевод сайта на несколько языков: нажал кнопку, получил русскую, английскую и испанскую версии. Для международных клиентов это экономит время на переводе, но качество машинного перевода всё равно нужно проверить глазами.

**Ограничения.** Webflow обычно дороже Tilda и Framer: платишь и за тариф сайта, и за тариф рабочего пространства (workspace). Для клиентов с простым сайтом это может быть избыточно. Зато для бизнесов с блогом, командой и регулярным обновлением контента — идеально.

---

### Framer AI — лендинг из одного промпта

**Что это.** Framer — дизайн-инструмент, который научился генерировать полные лендинги из текстового описания. Ты пишешь: «Лендинг для студии йоги в Москве. Современный минималистичный стиль, тёплые тона, секции: герой, о нас, расписание, отзывы, запись на пробное» — и через короткое время получаешь готовую страницу с текстами, изображениями и адаптивной вёрсткой.

**Сильные стороны.** Framer исторически делает красивые анимации, которые сложно повторить в Webflow без знания кода. AI сохраняет этот уровень визуального качества. Бесплатно сайт публикуется на поддомене Framer, свой домен подключается на платных тарифах (условия на сайте Framer).

**Framer vs Webflow.** Framer, как правило, быстрее по генерации и красивее из коробки. Webflow выигрывает по возможностям CMS и масштабируемости для больших сайтов. Для лендинга на один продукт — Framer. Для корпоративного сайта с каталогом — Webflow.

**Ограничение.** Framer — прежде всего инструмент сайтов и маркетинговых страниц, не для сложных веб-приложений. Если клиент хочет личный кабинет или интеграцию с CRM — нужен Webflow или гибрид с Claude Code.

### Bubble.io + AI-плагины — полноценные веб-приложения

**Что это.** Bubble — один из самых мощных no-code инструментов для создания полноценных веб-приложений: с базой данных, авторизацией, логикой, платёжными интеграциями. Добавь AI-функции или подключение моделей через API (OpenAI, Claude) — и приложение начинает думать.

**Типичные проекты на Bubble.** Marketplace (как Airbnb без кода), SaaS-дашборды, платформы для онлайн-курсов, CRM для малого бизнеса. Всё это без написания серверного кода.

**Bubble + Claude API.** Через плагин или прямые API-вызовы подключаешь Claude (LLM — эл-эл-эм — большую языковую модель). Например: пользователь загружает документ → Bubble отправляет текст в Claude API → Claude возвращает краткое содержание → Bubble сохраняет в базу и показывает пользователю. Это работающий AI-продукт без единой строчки серверного кода.

**Минус Bubble.** Крутая кривая обучения: основы осваиваются не за вечер. Платные тарифы нужны для запуска, цена зависит от нагрузки приложения (тарифы на сайте Bubble). Производительность ниже, чем у написанного кода. Для MVP и малого трафика — отлично, для стартапа с ростом — нужен eventual migration на код.

### Lovable — конкурент Claude Code для не-программистов

**Что это.** Lovable (бывший GPT Engineer) — инструмент, который генерирует приложение из описания. Похож на Claude Code, но через веб-интерфейс, без терминала. Ты описываешь приложение в чате, Lovable собирает интерфейс и логику, есть встроенный бэкенд Lovable Cloud (база данных, регистрация и вход) и публикация.

**Про данные клиентов.** С 9 сентября 2026 данные на тарифах Free и Pro могут использоваться для обучения моделей, пока в настройках не включён «Data collection opt out». Для клиентских проектов включай его сразу.

**Lovable vs Claude Code.** Lovable проще для старта — не нужно ничего устанавливать. Claude Code гибче и мощнее — работает с любым стеком, любым облаком, даёт полный контроль над кодом. Для новичка, которому нужен MVP быстро — Lovable. Для серьёзного продукта с долгим сроком жизни — Claude Code.

**Гибрид.** Некоторые разработчики используют Lovable для быстрого прототипа, затем экспортируют код и дорабатывают через Claude Code. Это работает.

### Bolt.new — Stackblitz AI в браузере

**Что это.** Bolt.new от Stackblitz — генератор приложений прямо в браузере. Не нужно ничего устанавливать: всё работает в облаке. Пишешь промпт — получаешь работающий проект с фронтендом и бэкендом. Хостинг и домены входят в сам сервис (Bolt Cloud): бесплатный адрес на bolt.host, свой домен — на платных тарифах.

**Сильная сторона.** Bolt очень быстрый для простых задач: лендинг, форма обратной связи, простой дашборд. Интеграция со Stackblitz значит, что код выполняется прямо в браузере — можно показать клиенту результат без отдельного деплоя, прямо в чате.

**Ограничения.** Сложная бизнес-логика, кастомные интеграции, работа с базами данных — это всё требует либо перехода на Claude Code, либо значительных ручных правок.

### Когда использовать no-code vs Claude Code

| Критерий | No-code (v0/Framer/Webflow) | Claude Code |
|---|---|---|
| **Скорость запуска** | часы | дни |
| **Кастомизация** | Средняя | Полная |
| **Стоимость инструментов** | по тарифам сервисов | подписка Claude (Pro и выше) или оплата по токенам через API |
| **Хостинг** | Включён в тариф или отдельная плата | Самостоятельно (Cloudflare, Vercel) |
| **Типовые задачи** | ✅ Отлично | Избыточно |
| **Нестандартная логика** | ❌ Сложно/невозможно | ✅ Полный контроль |
| **Масштабирование** | Ограничено тарифом | Неограничено |
| **Долгосрочная поддержка** | Зависишь от платформы | Полный контроль |
| **Интеграции с API** | Через плагины или Zapier (Зэпир — платформа интеграций между сервисами) | Нативно любые |
| **Подходит для** | Лендинги, MVP, малый бизнес | SaaS, сложные продукты |

**Практическое правило:** если проект типовой (лендинг, визитка, простой каталог) и не требует кастомной логики — no-code. Если есть личный кабинет, интеграции или нестандартные требования — гибрид или чистый Claude Code. Актуальные цены и версии: [Актуальное сейчас](https://aimayak.com/ru/now/).

### Гибридный подход: no-code UI + Claude Code бэкенд

🎨 **Образ:** Рестораны часто покупают готовые полуфабрикаты (тесто, соусы), но финальное приготовление — за поваром. No-code инструменты — это полуфабрикат интерфейса. Claude Code — шеф-повар, который доводит блюдо до ресторанного уровня.

**Workflow гибридного проекта:**

```
[ЭТАП 1: Дизайн — v0 / Framer]
Промпт → UI-компоненты / лендинг
Итерация → финальный дизайн утверждён
↓
[ЭТАП 2: Кастомизация — Claude Code]
Вставить код из v0
Подключить API (Stripe, Telegram, CRM)
Добавить авторизацию
Добавить валидацию форм
Настроить бизнес-логику
↓
[ЭТАП 3: Деплой — Cloudflare / Vercel]
Одной командой через Claude Code
CDN, SSL, custom domain — автоматически
↓
[СДАЧА КЛИЕНТУ]
Обучение (15 мин): как редактировать контент
Поддержка: 1 месяц по договору
```

### Бизнес-модель «сборщика»

Это конкретная ниша для предпринимателей из этого курса. Ты не разработчик и не дизайнер — ты эксперт по сборке. Знаешь, какой инструмент для какой задачи, умеешь быстро собрать результат и берёшь плату за скорость и экспертизу.

**Что можно предлагать:**

- Лендинг (Framer + кастомизация)
- Корпоративный сайт с CMS (Webflow)
- MVP приложения (Bubble или гибрид с Claude Code)
- Редизайн существующего сайта (компоненты из v0 + Claude Code)

**Почему клиенты платят.** Они сами могли бы попробовать Framer — но потратят неделю на обучение, ещё неделю на итерации. Ты делаешь это быстрее. Разница в цене — это их время, помноженное на их почасовую ставку. Цены задаёт рынок и твои затраты; доход не гарантирован. Как посчитать цену, смотри в уроке [Цены и монетизация](39-monetization-pricing.md).

**Как найти клиентов.** Малый бизнес без сайта или со старым сайтом — везде. Локальные рестораны, салоны, юристы, врачи, ателье, туристические компании. Им не нужен сложный продукт — им нужен приличный сайт с формой обратной связи за разумные деньги.

## Практика

### Задача: собрать лендинг за 35 минут с помощью v0 + Claude Code

**Сценарий:** клиент просит сделать лендинг для онлайн-школы английского языка. Нужны: секция герой, преимущества, тарифы, форма записи, которая отправляет заявку в Telegram.

---

**Шаг 1: Генерация дизайна в v0 (10 минут)**

Зайди на [v0.app](https://v0.app) и введи промпт:

```
Создай лендинг для онлайн-школы английского языка. Стиль: современный, 
профессиональный, синяя цветовая схема. Секции:
1. Герой: заголовок "Заговори на английском за 3 месяца", подзаголовок, 
   кнопка "Записаться на пробный урок"
2. Три преимущества: живые уроки, гибкое расписание, сертификат
3. Тарифы: Базовый ($49/мес), Стандарт ($89/мес), Премиум ($149/мес) — 
   карточки с характеристиками и кнопкой
4. Форма записи: имя, email, телефон, удобное время, кнопка отправить
Используй Tailwind CSS, компонент должен быть на React.
```

Итерируй если нужно («сделай герой секцию выше», «тарифы покажи горизонтально», «добавь иконки к преимуществам»). Финальный вариант — скопируй весь код.

---

**Шаг 2: Инициализация проекта в Claude Code (5 минут)**

```bash
# В терминале:
mkdir english-school-landing
cd english-school-landing
```

Открой Claude Code в этой папке и напиши:

```
Создай новый Next.js проект с Tailwind CSS. 
Структура: app/page.tsx для главной страницы.
Установи зависимости и проверь что всё запускается.
```

---

**Шаг 3: Вставка кода из v0 (5 минут)**

Скажи Claude Code:

```
Вот React-компонент, который я сгенерировал в v0. 
Вставь его в app/page.tsx и убедись что все импорты правильные, 
Tailwind работает, компонент рендерится без ошибок.

[вставь сюда код из v0]
```

Claude Code разберётся с импортами, исправит конфликты, запустит проект.

---

**Шаг 4: Добавление Telegram-интеграции (10 минут)**

```
Добавь обработку формы записи. Когда пользователь нажимает "Записаться", 
данные должны отправляться в Telegram-бота.

Мой Telegram Bot Token: [твой токен]
Chat ID для получения заявок: [твой chat_id]

Формат сообщения в Telegram:
🎓 Новая заявка на пробный урок
Имя: {имя}
Email: {email}
Телефон: {телефон}
Удобное время: {время}

Добавь:
1. API-роут app/api/contact/route.ts для обработки формы
2. Валидацию полей (имя минимум 2 буквы, валидный email, телефон)
3. Состояние загрузки на кнопке
4. Сообщение об успехе / ошибке пользователю
5. Переменные окружения для токена бота
```

---

**Шаг 5: Деплой на Vercel (5 минут)**

```
Подготовь проект к деплою на Vercel:
1. Создай .env.example с нужными переменными
2. Добавь vercel.json если нужны особые настройки
3. Убедись что .gitignore игнорирует .env
4. Инициализируй git и сделай первый коммит

Затем задеплой командой: npx vercel --prod
```

После деплоя Claude Code покажет URL — отправь клиенту для согласования.

**Про бесплатные тарифы.** Тариф Hobby у Vercel — только для личных некоммерческих проектов. Для клиентского (коммерческого) сайта нужен платный тариф Vercel (Pro, на октябрь 2026 — от $20 в месяц за разработчика) или другой хостинг, например Cloudflare Pages.

| **Bolt.new** | Приложения в браузере от Stackblitz | Есть бесплатный тариф с лимитами | bolt.new |
| **Vercel** | Деплой Next.js, кастомные домены | Hobby (некоммерческий) бесплатно; для бизнеса Pro | vercel.com |
| **Zapier / Make** | Интеграции между no-code инструментами | Есть бесплатные тарифы с лимитами | zapier.com / make.com |

**Стек для «сборщика» с минимальными расходами на старте:**

- v0 (бесплатный план) + Claude Code (входит в платную подписку Claude, на бесплатном тарифе недоступен) + Cloudflare Pages или Vercel + Framer (бесплатный тариф)
- Для клиентских (коммерческих) проектов бесплатные тарифы часто не подходят: читай условия каждого сервиса
