# Музыка через AI — Suno и звуковой дизайн

**Модуль:** Content Factory AI | **Время:** ~20 мин теории + 30 мин практики

---

## Суть урока

AI-музыка для предпринимателя — это не про то чтобы стать музыкантом, а про то чтобы закрыть три конкретных потребности: фоновая музыка для видео, джинглы для бренда, звуковое оформление подкастов — и всё это без отдельного композитора и дизайнера звука.

🎨 **Образ:** Раньше сделать джингл для бренда — это нанять музыканта, студию, несколько встреч, пару недель и отдельный бюджет. Сейчас — 10 минут в Suno, промпт, три варианта на выбор, скачал. Это не хуже и не лучше живой музыки — это другой инструмент для другого масштаба.

---

## Ключевые концепции

- Suno AI — полные треки из текстового промпта (промпт — запрос к AI), включая вокал
- Udio — другой сервис AI-музыки; с октября 2025 скачивание песен там отключено (см. раздел про Udio)
- Промпт для музыки: жанр + настроение + инструменты + темп + длина
- Claude помогает написать lyrics (текст песни) и промпты для Suno
- Коммерческое использование: правила разные в 2026, важно проверять
- ElevenLabs Sound Effects — короткие звуки для интерфейсов и подкастов

## Теория

### Зачем AI-музыка предпринимателю

**Три основных сценария:**

**1. Фоновая музыка для YouTube/видео**
Стоковая музыка платная или идёт с лицензионными условиями, и её используют многие. AI-музыка уникальна, генерируется под настроение конкретного видео, а при платном тарифе с коммерческими правами её можно использовать в монетизированном контенте.

**2. Джингл для бренда**
Короткий 10-30 секундный трек с твоим брендовым звуком. Раньше — дорого и долго. Теперь — несколько промптов, выбрал лучший, адаптировал.

**3. Подкаст/курс звуковое оформление**
Интро/аутро, переходная музыка между разделами, фоновая атмосфера для учебных секций.

🎨 **Образ:** Музыка в видео — как освещение в ресторане. Плохое освещение ты не замечаешь осознанно, но чувствуешь дискомфорт. Правильное — атмосфера, уют, желание остаться. Фоновая музыка работает так же.

### Suno AI — полные треки из промпта

Suno создаёт полноценные треки включая:

- Инструментальную часть
- Вокал (на любом языке)
- Структуру: куплет-припев-бридж

**Интерфейс:**
Заходишь на [suno.com](https://suno.com) → «Create» → пишешь промпт → получаешь два варианта → слушаешь → продолжаешь или скачиваешь.

**Планы (на октябрь 2026):**

- Free: бесплатно, 50 кредитов в день, модель v6-mini, песни скачать нельзя, коммерческих прав нет
- Pro: $8 в месяц (дешевле при годовой оплате), 2 500 кредитов в месяц, коммерческие права, до 20 скачиваний песен в месяц
- Premier: $24 в месяц (дешевле при годовой оплате), 10 000 кредитов в месяц, до 60 скачиваний, Suno Studio
- Актуальные цены и условия: [suno.com/pricing](https://suno.com/pricing), [Актуальное сейчас](https://aimayak.com/ru/now/)

**Режимы** (названия в интерфейсе меняются):

- **Custom** — пишешь lyrics сам + выбираешь стиль
- **Простой режим** — описываешь настроение, Suno сам пишет слова

### Промпты для Suno — формула

Музыкальный промпт работает по формуле:

```
[жанр] [темп] [настроение] [инструменты] [особенности]
```

**Примеры хороших промптов:**

```
# Фоновая для бизнес-видео
upbeat corporate background music, 120bpm, 
optimistic and professional, piano and strings, 
no vocals, suitable for YouTube

# Джингл для бренда
catchy brand jingle, 15 seconds, 
energetic and memorable, 
electronic with guitar, 
male vocal humming, modern startup vibe

# Подкаст интро
podcast intro music, 30 seconds, 
lo-fi hip hop, chill and focused, 
soft beat with vinyl crackle,
fade in fade out, no vocals

# Курс переходная музыка
educational ambient music, 10 seconds,
calm and focused, soft piano,
neutral mood, suitable for online course transitions
```

**Что работает:**

- Конкретный темп (BPM)
- Конкретная длина
- Указание «no vocals» если не нужен вокал
- Назначение (for YouTube / for podcast / for e-learning)

**Что не работает:**

- «Сделай красивую музыку» — слишком общо
- Перечисление 10+ параметров — модель путается
- Несовместимые стили («jazz metal ambient»)

### Udio — что изменилось

Udio ([udio.com](https://udio.com)) был конкурентом Suno. В конце 2025 года сервис заключил соглашения с музыкальными лейблами, и с 30 октября 2025 года скачивание песен и стемов отключено: музыка остаётся внутри платформы. Лицензированная платформа была анонсирована на 2026 год. Что с ней сегодня и вернулось ли скачивание, проверь на сайте.

🎨 **Образ:** Udio на октябрь 2026 похож на студию звукозаписи, где слушать можно, а плёнку домой не отдают. Для задач, где нужен файл (фон для видео, джингл, звук для курса), Udio сегодня не подходит.

**Альтернативы Suno на октябрь 2026:** Google Lyria в приложении Gemini (треки до трёх минут с вокалом или без; условия коммерческого использования на страницах Google не указаны, читай политику сервиса) и Soundraw (фоновая музыка; по данным сервиса, на созданные треки действует лицензия на коммерческое использование). Сравнивай на своих промптах и читай лицензию перед монетизацией.

### Claude помогает написать lyrics и промпты

Claude сам музыку не генерирует, но он отличный помощник в подготовке:

**1. Lyrics для Custom Mode в Suno:**

```
Напиши lyrics для короткого брендового джингла.
Бренд: [название]
Суть: [чем занимается]
Длина: 30 секунд (4-6 строк)
Стиль: упbeat, запоминающийся, без клише
Язык: русский

Формат: куплет (4 строки) + припев (2 строки)
```

**2. Оптимизация промпта для Suno:**

```
Мне нужна фоновая музыка для YouTube канала об [теме].
Аудитория: [описание]
Настроение видео: [описание]

Напиши 3 варианта промпта для Suno в формате:
[жанр] [темп] [настроение] [инструменты] [особенности]
Каждый вариант — разный стиль, под одно назначение.
```

**3. Описание для звуковой коллекции:**

```
У меня есть 10 треков для моего YouTube канала.
Помоги создать систему именования и тегов:
- по настроению (energetic / calm / focused / inspiring)
- по длине (intro / transition / background / outro)
- по видео-типу (tutorial / vlog / announcement)
```

### Коммерческое использование — правила на октябрь 2026

**Suno:**

- Free: коммерческое использование нельзя, скачивания нет
- Pro и Premier: коммерческие права и ограниченное число скачиваний в месяц
- Важно: Suno может изменять условия, всегда читай актуальный ToS на сайте

**Udio:**

- Скачивание песен отключено, условия монетизации проверяй на сайте перед любым использованием

**Общее правило:**
Если видео монетизировано на YouTube или контент используется для продажи — нужен платный тариф с коммерческими правами (на Suno это Pro или Premier). Сохраняй скриншот условий на день создания трека. Это не юридическая консультация: сомневаешься — спроси юриста.

## Практика

1. Создай аккаунт в Suno (бесплатно, Google login):

Зайди на [suno.com](https://suno.com) → Sign in with Google → бесплатные кредиты на старте (на Free 50 в день; песни скачать нельзя, для скачивания и коммерческого использования нужен платный тариф)

2. Сгенерируй фоновую музыку для YouTube через Claude:

```
Промпт для Claude:
Напиши 3 варианта промпта для Suno.
Назначение: фоновая музыка для YouTube канала об [твоя тема].
Формат промпта: жанр + BPM + настроение + инструменты + длина.
Без вокала.
```

3. Запусти каждый промпт в Suno, слушай результаты (6 треков = 3 промпта × 2 варианта)

4. Напиши через Claude lyrics для 15-секундного джингла своего бренда:

```
Бренд: [твой]
Суть: [одно предложение]
Стиль: [что хочешь]
Напиши 4 строки + припев 2 строки
```

5. Создай трек в Suno через Custom Mode: вставь lyrics от Claude + выбери стиль

6. Зайди на ElevenLabs Sound Effects, создай звук перехода для своих видео:

```bash
# Попробуй несколько вариантов:
"cinematic whoosh, 1 second, clean"
"soft page turn sound, 0.5 seconds"
"subtle tech transition, 0.8 seconds"
```

## Ключевые выводы

> Suno и похожие сервисы не заменяют живых музыкантов для сложных проектов, но закрывают значительную часть потребностей контент-предпринимателя: фоновая музыка, джинглы, переходы — быстро и уникально, а при платном тарифе с коммерческими правами и с понятной лицензией.

> Хороший промпт для музыки = жанр + темп в BPM + настроение + инструменты + длина — пять элементов дают предсказуемый результат в отличие от «сделай что-нибудь красивое».

> Claude в музыкальном процессе — это автор lyrics и оптимизатор промптов: он не генерирует звук, но помогает сформулировать точное техзадание для инструментов которые генерируют.
