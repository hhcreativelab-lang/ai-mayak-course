# Claude Code Desktop — нативное приложение на компьютер

**Модуль:** 2. Быстрый старт | **Время:** ~30 мин теории + 30 мин практики

---

## Суть урока

Есть два способа работать с Claude Code: через расширение VS Code (Вэ-эС Код — популярный редактор кода от Microsoft) (см. предыдущий урок) и через нативное Desktop-приложение — программу которую ставишь на компьютер как любое другое приложение. Это инструмент для ежедневной работы: три вкладки, параллельные сессии, встроенный терминал (терминал — программа для работы с командной строкой), планировщик задач, переключение моделей одним кликом.

🎨 **Образ:** VS Code с расширением — как нанять повара прямо в твой ресторан. Desktop App — как открыть собственный ресторан целиком: кухня, зал, касса, всё в одном месте, под одной крышей.

---

## Ключевые концепции

- **Claude Code Desktop** — нативное приложение (macOS / Windows), три вкладки: Chat, Cowork, Code
- **Вкладка Code** — основная: интерактивная работа с кодом и файлами на твоём компьютере
- **Вкладка Chat** — обычный диалог с Claude (без доступа к файлам), аналог claude.ai в браузере
- **Вкладка Cowork** — Dispatch (постоянный разговор с Claude, которому можно отправлять задачи в том числе с телефона) и более долгая агентная работа (агент — автономная программа-исполнитель): исследования, документы, таблицы
- **Permission Modes** — сколько свободы даёшь агенту (от "спрашивай всё" до "делай сам")
- **Модели** — Haiku (быстро), Sonnet (быстрее и дешевле), Opus (по умолчанию), Fable (самые долгие и сложные задачи) — переключаются прямо во время сессии. Актуальные названия и версии: [Актуальное сейчас](https://aimayak.com/ru/now/)
- **Параллельные сессии** — несколько агентов (автономных программ-исполнителей) работают одновременно, каждый в своей вкладке
- **Scheduled Tasks** — планировщик: агент запускается сам по расписанию

## Теория

### Установка Desktop App

🎨 **Образ:** Установка Claude Code Desktop — как установить Word или Photoshop. Скачал, открыл, вошёл в аккаунт. Никакого Node.js, никаких npm (эн-пи-эм — менеджер пакетов Node.js) команд, никакого терминала для начала.

**Системные требования:**

- **macOS 13.0+** (Ventura и новее) — Intel или Apple Silicon
- **Windows 10 1809+** или Windows Server 2019+
- Linux — приложение в **бете** (Ubuntu и Debian, установка через apt или .deb); терминальная версия (CLI, интерфейс командной строки) работает на Linux без ограничений
- 4 GB RAM, интернет, Git (гит — система контроля версий кода): он нужен для изолированных сессий (worktree)

**Способ 1 — Прямое скачивание:**

| Платформа | Ссылка |
|---|---|
| **macOS Universal** (Intel + Apple Silicon) | [claude.ai/api/desktop/darwin/universal/dmg/latest/redirect](https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect) |
| **Windows x64** | [claude.ai/api/desktop/win32/x64/setup/latest/redirect](https://claude.ai/api/desktop/win32/x64/setup/latest/redirect) |
| **Windows ARM64** | [claude.ai/api/desktop/win32/arm64/setup/latest/redirect](https://claude.ai/api/desktop/win32/arm64/setup/latest/redirect) |

**Способ 2 — Linux (бета):** установка через apt или пакет .deb для Ubuntu и Debian, инструкция: [Claude Desktop on Linux](https://code.claude.com/docs/en/desktop-linux).

> Команда `brew install --cask claude-code` ставит терминальную версию Claude Code, а не это приложение. Про терминальную версию — в уроке [Режимы запуска CLI](08-work-modes.md).

После скачивания: открыл DMG (macOS) или Setup.exe (Windows) → установил как обычное приложение → запустил → вошёл в аккаунт Anthropic → открыл вкладку Code.

**Требуется платный план:** Pro, Max, Team или Enterprise. Бесплатный план Claude.ai не включает Claude Code. Актуальные цены тарифов: [Актуальное сейчас](https://aimayak.com/ru/now/).

### Три вкладки: Chat, Cowork, Code

🎨 **Образ:** Три вкладки — как три этажа одного здания. Первый этаж (Chat) — зал для переговоров, можно просто поговорить. Второй этаж (Cowork) — цех, куда можно отправить задачу даже с телефона. Третий этаж (Code) — твой личный кабинет с компьютером: здесь ты и агент работаете вместе над файлами.

| Вкладка | Что делает | Для чего |
|---|---|---|
| **Chat** | Диалог с Claude без доступа к файлам | Вопросы, анализ, объяснения — без кода |
| **Cowork** | Dispatch и долгая агентная работа | Исследования, документы, таблицы; задачи с телефона (Dispatch нужен тариф Pro или Max) |
| **Code** | Работа с локальными файлами на твоём компьютере | Программирование, автоматизация, проекты |

**Основная вкладка для курса — Code.** Именно здесь агент читает твои файлы, пишет код, запускает команды в терминале.

### Интерфейс вкладки Code

🎨 **Образ:** Интерфейс вкладки Code — как кабина самолёта. Боковая панель слева (список сессий) — это GPS и карты. Центр — стекло кабины через которое видишь что делаешь. Снизу — педали и рычаги (модели, режимы, ввод).

**Боковая панель (sidebar):**

- Список всех сессий — каждая сессия это отдельный разговор с агентом
- Кнопка `+ New session` (Cmd+N / Ctrl+N) — новый чистый разговор
- Раздел **Scheduled** — сессии плановых задач
- Раздел **Dispatch** — задачи отправленные с телефона
- Кнопка **Routines** — создание и управление расписанием
- Кнопка **Customize** — подключение MCP (эм-си-пи, Model Context Protocol — протокол контекста модели), плагинов, коннекторов

**Поле ввода (снизу):**

- Текст запроса
- Кнопка `+` — прикрепить файл, изображение, PDF
- Дропдаун **Environment** — Local / Cloud / SSH (на Windows ещё WSL)
- Дропдаун **Model** — выбор модели (Haiku / Sonnet / Opus / Fable)
- Дропдаун **Mode** — режим разрешений
- Кнопка отправки / стоп (Esc)

**Панели (можно открывать и скрывать):**

| Панель | Что показывает | Горячая клавиша |
|---|---|---|
| Chat | Разговор с Claude | — |
| Diff | Изменения в коде (+/-) | Cmd+Shift+D |
| Browser | Встроенный браузер: твоё запущенное приложение и любые сайты | Cmd+Shift+B |
| Terminal | Встроенный терминал | Ctrl+` |
| Tasks | Фоновые задачи и суб-агенты | — |
| Plan | План действий Claude | — |

**Режимы просмотра (Transcript view):**

- **Normal** — вызовы инструментов свёрнуты в краткие сводки
- **Verbose** — видно все шаги, все вызовы инструментов
- **Thinking** — вызовы инструментов свёрнуты, но видно рассуждения Claude
- Переключение: `Ctrl+O`

### Управление моделями

🎨 **Образ:** Выбор модели — как выбор инструмента на стройке. Haiku — молоток для мелких задач. Sonnet — перфоратор: быстрее и дешевле. Opus — строительный кран, на подписках включён по умолчанию. Fable — тяжёлая техника для самых долгих и сложных задач. Переключаешь прямо во время работы — не нужно останавливать стройку.

Переключение модели: дропдаун рядом с кнопкой отправки. Работает **во время сессии**, не нужно начинать заново.

Модели на октябрь 2026 (актуальный список: [Актуальное сейчас](https://aimayak.com/ru/now/)):

| Модель | Алиас | Для чего | Скорость / Цена |
|---|---|---|---|
| **Haiku 4.5** | `haiku` | Простые и быстрые задачи | Самый быстрый / дешёвый |
| **Sonnet 5.5** | `sonnet` | Повседневная работа | Быстрее и дешевле Opus |
| **Opus 5.5** | `opus` | Сложные рассуждения, архитектурные решения | Модель по умолчанию |
| **Fable 5.1** | `fable` | Самые долгие и сложные задачи | Мощный / на подписках может списываться из usage credits |
| **OpusPlan** | `opusplan` | Opus планирует, Sonnet выполняет | Гибридный |

У Fable 5.1, Opus 5.5 и Sonnet 5.5 окно контекста (контекст — содержание разговора видимое AI) 1 млн токенов, отдельная версия с `[1m]` им не нужна.

**Default (дефолт — стандартное значение по умолчанию) модель:** на всех подписках (Pro, Max, Team, Enterprise) и в API по умолчанию стоит Opus 5.5. Раньше на Pro по умолчанию шёл Sonnet, сейчас это не так.

**Уровни усилий (Effort levels):**

Можно выбрать интенсивность рассуждения: `low`, `medium`, `high`, `xhigh`, `max`. Набор уровней зависит от модели: посмотри, что предлагает меню для выбранной.

- Меню: `Cmd+Shift+E`
- Или напиши `ultrathink` в промпте (промпт — текстовый запрос к AI) — Claude будет думать глубже для этого запроса

**Extended thinking (расширенное рассуждение):**

- У Opus 5.5, Sonnet 5.5 и Fable расширенное рассуждение включено всегда, отдельной кнопки нет
- Рассуждения Claude видны в режиме Thinking или Verbose (переключение `Ctrl+O`)

### Режимы разрешений (Permission Modes)

🎨 **Образ:** Permission Modes — это насколько ты доверяешь строителю ключи от квартиры. Manual = рабочий спрашивает перед каждым шагом. Accept edits = рабочий редактирует сам, но спрашивает перед включением газа. Auto = рабочий делает всё с видеокамерой наблюдения. Bypass = полное доверие без видеокамеры — только для изолированных стендов.

Выбор: дропдаун рядом с кнопкой отправки. Горячая клавиша: `Cmd+Shift+M`.

| Режим | Поведение | Когда использовать |
|---|---|---|
| **Manual** (значение `default`; раньше назывался Ask permissions) | Спрашивает перед каждым файлом и командой | Обучение, незнакомые задачи |
| **Accept edits** (раньше Auto accept edits) | Редактирует файлы сам, спрашивает перед командами | Уверен в задаче, хочешь скорость |
| **Plan** (раньше Plan Mode) | Только анализирует, ничего не меняет | Понять что Claude планирует сделать |
| **Auto** | Работает без обычных вопросов, а отдельная модель-проверяющая сверяет каждое действие с твоей просьбой | Опытные пользователи, доверенные задачи |
| **Bypass permissions** | Никаких вопросов вообще | Только в изолированных контейнерах! |

Режим Auto доступен не везде и зависит от модели и тарифа. Название и состав режимов смотри в выпадающем списке своей версии приложения.

### Параллельные сессии

🎨 **Образ:** Параллельные сессии — как несколько строительных бригад на разных этажах. Первая бригада делает кровлю, вторая — электрику, третья — отделку. Ты как прораб ходишь и проверяешь каждую. Никто не мешает друг другу.

Каждая сессия получает **изолированный Git worktree** — агент работает в своей копии репозитория, не пересекается с другими.

**Управление сессиями:**

| Действие | Mac | Windows |
|---|---|---|
| Новая сессия | `Cmd+N` | `Ctrl+N` |
| Закрыть сессию | `Cmd+W` | `Ctrl+W` |
| Следующая сессия | `Ctrl+Tab` | `Ctrl+Tab` |
| Предыдущая сессия | `Ctrl+Shift+Tab` | `Ctrl+Shift+Tab` |
| Открыть рядом | `Cmd+клик` на сессии | `Ctrl+клик` на сессии |

**Side Chat** — боковой вопрос не прерывающий основной разговор:

- `Cmd+;` (macOS) / `Ctrl+;` (Windows)
- Или напиши `/btw` в промпте

### Среды выполнения (Environments)

🎨 **Образ:** Environment — как выбрать где работает твой агент. Local — агент в твоём офисе. Cloud — агент в облаке (работает даже когда ты ушёл домой). SSH — агент на удалённом сервере.

| Среда | Где работает агент | Преимущества |
|---|---|---|
| **Local** | На твоём компьютере | Прямой доступ к файлам, максимальная скорость |
| **Cloud** | В облаке Anthropic (облачная сессия) | Работает при закрытом приложении, несколько репозиториев |
| **SSH** | На удалённой машине | Работа с production (продакшен — рабочая среда) сервером, VPS, Dev Container |

**SSH подключение:**

1. Дропдаун Environment → `+ Add SSH connection`
2. Заполни: Name, SSH Host (`user@hostname`), Port (22 по умолчанию), Identity File
3. Claude Code устанавливается на удалённую машину автоматически

### Плановые задачи (Scheduled Tasks)

🎨 **Образ:** Scheduled Tasks — как настроить будильник для агента. Ты уснул — агент проснулся, сделал работу, лёг спать до следующего раза. Утром видишь готовый результат.

Создание: вкладка Code → **Routines** в sidebar → **New routine** → Local.

**Поля:**

- **Name** — название (например: `morning-report`)
- **Instructions** — что делать Claude (обычный текст на русском)
- **Schedule** — расписание

**Варианты расписания:**

| Тип | Пример |
|---|---|
| Manual | Только ручной запуск |
| Hourly | Каждый час |
| Daily | Каждый день в 09:00 |
| Weekdays | По будням в 08:30 |
| Weekly | По понедельникам в 10:00 |

Минимальный интервал: **1 минута**.

**Локальные vs облачные:**

- Локальные — работают пока приложение открыто, доступ к твоим файлам
- Облачные (Routines) — работают даже при выключенном компьютере, можно запустить через API (эй-пи-ай, Application Programming Interface — интерфейс программирования приложений) или GitHub event, минимальный интервал 1 час

**Совет:** локальные задачи работают, только пока приложение запущено и компьютер не спит. Включи **Keep computer awake** (`Settings → This computer → System`), если используешь ночные задачи.

### Управление компьютером (Computer Use)

🎨 **Образ:** Computer Use — как дать агенту руку и показать экран. Он видит что происходит, может кликать, печатать, скроллить. Как удалённое управление, только агент сам решает что делать.

- Требует **Pro или Max** план (на Team и Enterprise недоступно); функция в режиме research preview (исследовательский показ)

**Три уровня доступа к приложениям:**

| Уровень | Приложения |
|---|---|
| View only (только смотреть) | Браузеры (Safari, Chrome) |
| Click only | Терминалы, IDE (ай-ди-и, Integrated Development Environment — среда разработки) |
| Full control | Всё остальное |

### Desktop vs VS Code Extension vs CLI — сравнение

🎨 **Образ:** Три инструмента для одной задачи. CLI — скальпель: точный, гибкий, в любых руках. VS Code — комбайн: редактор + агент в одном. Desktop — собственный хирургический центр: несколько операционных (сессий), своя аппаратура (панели), расписание дежурств (Scheduled Tasks).

| Функция | CLI | Desktop | VS Code |
|---|---|---|---|
| Параллельные сессии | Отдельные терминалы | ✅ Встроенный sidebar | ❌ |
| Встроенный терминал | ❌ | ✅ | ✅ (в VS Code) |
| Визуальный diff | ❌ | ✅ | ✅ |
| Прикрепление файлов/фото | ❌ | ✅ | ❌ |
| Planned Tasks UI | ❌ (через cron — планировщик автоматических задач) | ✅ | ❌ |
| Computer Use | ❌ | ✅ | ❌ |
| SSH среда | ❌ | ✅ | ❌ |
| Cloud (облачные сессии) | ❌ | ✅ | ❌ |
| Agent Teams (экспериментально, выключено по умолчанию) | ✅ | ❌ | ❌ |
| Автоматизация/скрипты | ✅ (`--print`) | ❌ | ❌ |
| Linux | ✅ | бета | ✅ |

**Вывод:** Desktop — лучший выбор для ежедневной ручной работы. CLI — для автоматизации и скриптов. VS Code — если хочешь всё в одном редакторе.

## Частые ошибки

❌ **Ошибка:** Открыл Desktop App и застрял в вкладке Chat — думаешь что Chat это Claude Code.

✅ **Правильно:** Chat — это просто разговор без файлов. Для работы с кодом нужна вкладка **Code**.

❌ **Ошибка:** Включил Fable для каждой задачи "чтобы было лучше".

✅ **Правильно:** Для большинства повседневных задач хватает модели по умолчанию, а Sonnet быстрее и дешевле. Fable нужен для действительно долгих и сложных задач, на подписках он может списываться из usage credits. Haiku — для быстрых простых запросов. Не жги токены (токены — минимальные единицы текста для AI) зря.

❌ **Ошибка:** Работаешь в режиме Bypass Permissions на реальных проектах с важными данными.

✅ **Правильно:** Bypass Permissions — только для изолированных тестовых сред. На реальных проектах используй Auto или Accept edits.

❌ **Ошибка:** Не знаешь что сессии изолированы — боишься запускать параллельные задачи.

✅ **Правильно:** Каждая сессия получает свой Git worktree. Они не мешают друг другу. Смело запускай 3-4 сессии параллельно.

❌ **Ошибка:** Запускаешь изолированные сессии, а Git не установлен.

✅ **Правильно:** Для сессий в отдельном worktree нужен Git. На Windows поставь [Git for Windows](https://git-scm.com/download/win) и запусти сессию снова.

## Практика

**Задание: Первый день в Desktop App**

**Шаг 1 — Установка (10 мин):**

1. Скачай Desktop App по ссылке для своей ОС (выше)
2. Установи как обычное приложение
3. Запусти → войди в аккаунт Anthropic

**Шаг 2 — Изучи интерфейс (5 мин):**

1. Открой вкладку Code
2. Нажми `Cmd+/` — просмотри список горячих клавиш
3. Открой дропдаун моделей — посмотри что доступно
4. Открой дропдаун Permission Modes — прочитай каждый режим

**Шаг 3 — Первая сессия (10 мин):**

1. Нажми `Cmd+N` — новая сессия
2. Выбери папку с проектом (или создай тестовую папку)
3. Напиши: `Что ты видишь в этой папке? Расскажи структуру.`
4. Посмотри как агент исследует файлы

**Шаг 4 — Параллельные сессии (5 мин):**

1. Нажми `Cmd+N` снова — создай вторую сессию
2. В первой спроси одно, во второй другое
3. Переключайся между ними `Ctrl+Tab`
4. Убедись что они не мешают друг другу

**Шаг 5 — Создай первую плановую задачу (10 мин):**

1. Нажми **Routines** в sidebar
2. Создай новую задачу: `morning-check`
3. Instructions: `Проверь все .md файлы в папке и напиши что нового появилось`
4. Schedule: Manual (пока только ручной запуск)
5. Запусти вручную — посмотри как работает

## Ключевые выводы

> Claude Code Desktop — нативное приложение с тремя вкладками. Для программирования нужна вкладка Code. Chat — это просто разговор без файлов.
