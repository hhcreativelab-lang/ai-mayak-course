# Claude Code в приложении для компьютера: начни без терминала

**Время:** ~30 мин теории + 40 мин практики

---

## Суть урока

Работать с Claude Code можно тремя способами: в терминале (окно, куда команды вводят текстом), в редакторе кода VS Code и в приложении Claude для компьютера. Этот урок про приложение. Оно ставится как любая другая программа, и терминал для начала открывать не нужно. Внутри: три вкладки, несколько сессий одновременно, встроенный терминал, планировщик задач и выбор модели одним щелчком.

Для тех, кто не программирует, это самый простой вход в Claude Code: поставил программу, выбрал папку и пишешь просьбы обычными словами, по-русски.

🎨 **Образ:** расширение для VS Code — как повар, которого наняли на чужую кухню. Приложение для компьютера — как свой ресторан целиком: кухня, зал и касса в одном месте, под одной крышей.

---

## Ключевые концепции

- **Claude Code Desktop** — так в документации называют Claude Code внутри приложения Claude для компьютера (macOS и Windows, для Linux есть бета-версия). В приложении три вкладки: Chat, Cowork, Code
- **Вкладка Code** — основная в этом уроке: работа с кодом и файлами на твоём компьютере
- **Вкладка Chat** — обычный диалог с Claude без доступа к файлам, то же, что claude.ai в браузере
- **Вкладка Cowork** — Dispatch (постоянный разговор с Claude, которому можно отправлять задачи, в том числе с телефона) и долгая самостоятельная работа агента: исследования, документы, таблицы. Агент — программа, которая сама выполняет задачу по шагам
- **Режимы разрешений (Permission modes)** — сколько свободы ты даёшь агенту: от «спрашивай обо всём» до «делай сам»
- **Модели** — Haiku (самая быстрая), Sonnet (быстрее и дешевле Opus), Opus (стоит по умолчанию), Fable (самые долгие и сложные задачи). Переключаются прямо во время работы. Актуальные названия и версии: [Актуальное сейчас](https://aimayak.com/ru/now/)
- **Параллельные сессии** — несколько разговоров с агентом идут одновременно, каждый со своей задачей
- **Плановые задачи (Scheduled tasks)** — агент запускается сам, по расписанию

## Теория

### Установка приложения

🎨 **Образ:** поставить приложение Claude — как поставить Word или Photoshop. Скачал, открыл, вошёл в аккаунт. Никаких дополнительных программ и никаких команд в терминале.

**Что нужно компьютеру:**

- **macOS 13.0 и новее** (Ventura и новее), процессор Intel или Apple Silicon
- **Windows 10 версии 1809 и новее** или Windows Server 2019 и новее
- Linux — приложение в **бете** (Ubuntu и Debian, установка через apt или пакет .deb). Версия для терминала (её называют CLI) работает на Linux без оговорок
- 4 ГБ оперативной памяти и интернет
- Git — программа, которая хранит историю изменений проекта. Нужна только для изолированных сессий (опция worktree, о ней ниже). На большинстве Mac она уже есть

**Способ 1 — скачать напрямую:**

| Система | Ссылка |
|---|---|
| **macOS Universal** (Intel и Apple Silicon) | [claude.ai/api/desktop/darwin/universal/dmg/latest/redirect](https://claude.ai/api/desktop/darwin/universal/dmg/latest/redirect) |
| **Windows x64** | [claude.ai/api/desktop/win32/x64/setup/latest/redirect](https://claude.ai/api/desktop/win32/x64/setup/latest/redirect) |
| **Windows ARM64** | [claude.ai/api/desktop/win32/arm64/setup/latest/redirect](https://claude.ai/api/desktop/win32/arm64/setup/latest/redirect) |

**Способ 2 — Linux (бета):** установка через apt или пакет .deb для Ubuntu и Debian. Инструкция (на английском): [Claude Desktop on Linux](https://code.claude.com/docs/en/desktop-linux).

> Команда `brew install --cask claude-code` ставит версию Claude Code для терминала, а не это приложение. Про неё — урок библиотеки [Режимы запуска CLI](08-work-modes.md).

После скачивания: открой файл DMG (macOS) или Setup.exe (Windows) → установи как обычную программу → запусти → войди в аккаунт Anthropic (тот же, что на claude.ai) → открой вкладку Code вверху окна.

**Нужен платный тариф:** Pro, Max, Team или Enterprise. На бесплатном тарифе Claude Code нет: при нажатии на вкладку Code приложение предложит перейти на платный. Актуальные цены тарифов: [Актуальное сейчас](https://aimayak.com/ru/now/).

### Три вкладки: Chat, Cowork, Code

🎨 **Образ:** три вкладки — как три этажа одного здания. Первый этаж (Chat) — переговорная, где можно просто поговорить. Второй этаж (Cowork) — цех, куда задачу можно отправить даже с телефона. Третий этаж (Code) — твой кабинет: здесь вы с агентом вместе работаете над файлами.

| Вкладка | Что делает | Для чего |
|---|---|---|
| **Chat** | Диалог с Claude без доступа к файлам | Вопросы, разбор, объяснения — без кода |
| **Cowork** | Dispatch и долгая самостоятельная работа агента | Исследования, документы, таблицы; задачи с телефона (для Dispatch нужен тариф Pro или Max) |
| **Code** | Работа с файлами на твоём компьютере | Программирование, автоматизация, проекты |

**Основная вкладка для курса — Code.** Именно здесь агент читает твои файлы, пишет код и запускает команды.

С 16 сентября 2026 Anthropic объединяет Chat и Cowork в один режим. Обновление приходит постепенно, сначала на тарифы Pro и Max. Если у тебя вместо этих двух вкладок одна — всё в порядке, вкладка Code работает так же.

### Интерфейс вкладки Code

🎨 **Образ:** вкладка Code — как кабина самолёта. Боковая панель слева (список сессий) — это карты и навигатор. Центр — лобовое стекло, через которое видно, что происходит. Внизу — рычаги и педали: модель, режим, поле ввода.

**Боковая панель:**

- Список всех сессий. Сессия — это отдельный разговор с агентом, со своей историей и своей папкой проекта
- Кнопка `+ New session` (Cmd+N на Mac, Ctrl+N на Windows) — новый чистый разговор
- Раздел **Scheduled** — сессии, которые запустились по расписанию
- Значок **Dispatch** у сессии — её запустил Dispatch, например по задаче с телефона
- Кнопка **Routines** — создание задач по расписанию и управление ими
- Кнопка **Customize** — подключение внешних сервисов (коннекторов), навыков и плагинов

**Поле ввода (внизу):**

- Текст просьбы
- Кнопка `+` — прикрепить файл, изображение или PDF
- Список **Environment** — где работает агент: Local, Cloud, SSH (на Windows ещё WSL)
- Список **Model** — выбор модели (Haiku, Sonnet, Opus, Fable)
- Список режимов разрешений рядом с кнопкой отправки
- Кнопка отправки, она же «стоп» (или клавиша Esc)

**Панели (можно открывать, скрывать и перетаскивать):**

| Панель | Что показывает | Горячая клавиша (Mac) |
|---|---|---|
| Chat | Разговор с Claude | — |
| Diff | Изменения в файлах: что добавлено и что убрано | Cmd+Shift+D |
| Browser | Встроенный браузер: твой запущенный сайт и любые другие сайты | Cmd+Shift+B |
| Terminal | Встроенный терминал | Ctrl+` |
| Tasks | Фоновые задачи и помощники-субагенты | — |
| Plan | План действий Claude | — |

**Режимы просмотра разговора (Transcript view):**

Ниже «вызов инструмента» — это одно действие Claude: прочитать файл, запустить команду.

- **Normal** — вызовы инструментов свёрнуты в короткие сводки
- **Thinking** — вызовы свёрнуты, но видны рассуждения Claude
- **Verbose** — видны все шаги и все вызовы инструментов
- Переключение: `Ctrl+O`

### Управление моделями

🎨 **Образ:** выбор модели — как выбор инструмента на стройке. Haiku — молоток для мелких дел. Sonnet — перфоратор: быстрее и дешевле. Opus — строительный кран, на платных тарифах стоит по умолчанию. Fable — тяжёлая техника для самых долгих и сложных работ. Менять инструмент можно прямо во время работы, стройку останавливать не нужно.

Модель переключается в списке рядом с кнопкой отправки. Это работает **посреди сессии**, начинать заново не нужно.

Модели на октябрь 2026 (актуальный список: [Актуальное сейчас](https://aimayak.com/ru/now/)):

| Модель | Короткое имя | Для чего | Скорость и цена |
|---|---|---|---|
| **Haiku 4.5** | `haiku` | Простые и быстрые задачи | Самая быстрая и дешёвая |
| **Sonnet 5.5** | `sonnet` | Повседневная работа | Быстрее и дешевле Opus |
| **Opus 5.5** | `opus` | Сложные рассуждения, устройство проекта | Модель по умолчанию |
| **Fable 5.1** | `fable` | Самые долгие и сложные задачи | Самая сильная; на части тарифов оплачивается через usage credits (доплата сверх подписки) |
| **OpusPlan** | `opusplan` | Opus составляет план, Sonnet выполняет | Смешанный режим |

У Fable 5.1, Opus 5.5 и Sonnet 5.5 окно контекста — 1 млн токенов (контекст — всё, что модель видит в разговоре; токен — кусочек текста). Отдельный вариант с пометкой `[1m]` им не нужен.

**Модель по умолчанию:** на всех платных тарифах (Pro, Max, Team, Enterprise) и при работе через API стоит Opus 5.5. Раньше на Pro по умолчанию был Sonnet, теперь это не так.

**Уровни усилия (Effort):**

Можно выбрать, насколько глубоко Claude обдумывает задачу: `low`, `medium`, `high`, `xhigh`, `max`. Набор уровней зависит от модели: посмотри, что предлагает меню для выбранной.

- Меню: `Cmd+Shift+E`
- Или напиши в просьбе слово `ultrathink` — для этого запроса Claude будет думать глубже

**Расширенное рассуждение (Extended thinking):**

- У Opus 5.5, Sonnet 5.5 и Fable оно включено всегда, отдельной кнопки нет
- Рассуждения Claude видны в режимах просмотра Thinking и Verbose (переключение `Ctrl+O`)

### Режимы разрешений (Permission modes)

🎨 **Образ:** режимы разрешений — это насколько ты доверяешь мастеру ключи от квартиры. Manual — мастер спрашивает перед каждым шагом. Accept edits — сам делает правки, но спрашивает, прежде чем включить газ. Auto — делает всё сам под присмотром камеры. Bypass permissions — полное доверие без камеры, только для пустого тестового помещения.

Режим выбирается в списке рядом с кнопкой отправки. Горячая клавиша: `Cmd+Shift+M`.

| Режим | Как себя ведёт | Когда выбирать |
|---|---|---|
| **Manual** (в файлах настроек называется `default`; раньше назывался Ask permissions) | Спрашивает перед каждой правкой файла и каждой командой | Пока учишься; в незнакомых задачах |
| **Accept edits** (раньше Auto accept edits) | Файлы правит сам, перед командами спрашивает | Задача понятна, хочется быстрее |
| **Plan** (раньше Plan mode) | Изучает проект и предлагает план, файлы не меняет | Чтобы увидеть, что Claude собирается делать |
| **Auto** | Работает без обычных вопросов, а отдельная модель-проверяющая сверяет действия с твоей просьбой | Когда освоился; для задач, которым доверяешь |
| **Bypass permissions** | Почти без вопросов | Только в изолированной тестовой среде, где нет ничего важного! |

Режим Auto появляется в списке, когда выбрана подходящая модель (Opus 4.6 и новее, Sonnet 4.6 и новее или Fable). В организации его может отключить администратор. Bypass permissions появляется только после того, как его включили в настройках. Точный состав списка смотри в своей версии приложения.

💡 **Если только начинаешь:** посмотри, какой режим выбран в списке, и поставь Manual. Он задаёт много вопросов, и в этом его смысл: ты видишь, что агент собирается сделать с файлами, до того как он это сделает. Выбранный режим приложение запоминает для каждой папки. На Accept edits переходи, когда задача тебе понятна.

### Параллельные сессии

🎨 **Образ:** параллельные сессии — как несколько бригад на разных этажах. Первая делает кровлю, вторая — электрику, третья — отделку. Ты, как прораб, обходишь всех и проверяешь работу.

У каждой сессии своя история разговора. Но если две сессии открыты в одной папке, они правят одни и те же файлы. Чтобы развести их, приложение умеет дать сессии **отдельную копию проекта**: для этого при запуске сессии рядом с названием ветки включают опцию **worktree**. Она работает только в папке, за которой следит Git (такую папку называют репозиторием), и требует установленного Git.

**Управление сессиями:**

| Действие | Mac | Windows |
|---|---|---|
| Новая сессия | `Cmd+N` | `Ctrl+N` |
| Закрыть сессию | `Cmd+W` | `Ctrl+W` |
| Следующая сессия | `Ctrl+Tab` | `Ctrl+Tab` |
| Предыдущая сессия | `Ctrl+Shift+Tab` | `Ctrl+Shift+Tab` |
| Открыть рядом | `Cmd+щелчок` по сессии | `Ctrl+щелчок` по сессии |

**Side chat** — боковой вопрос, который не сбивает основной разговор:

- `Cmd+;` (macOS) или `Ctrl+;` (Windows)
- Или напиши `/btw` в поле ввода

### Где работает агент (Environments)

🎨 **Образ:** среда — это место, где работает твой агент. Local — агент в твоём офисе. Cloud — агент в облаке и продолжает работать, даже когда ты ушёл домой. SSH — агент на удалённом сервере.

| Среда | Где работает агент | Чем удобна |
|---|---|---|
| **Local** | На твоём компьютере | Прямой доступ к файлам |
| **Cloud** | На серверах Anthropic (облачная сессия) | Работает при закрытом приложении, можно подключить несколько репозиториев |
| **SSH** | На удалённом компьютере, к которому ты подключаешься | Работа на своём сервере или на арендованной машине |

Новичку хватает Local. Остальное пригодится позже.

**Подключение по SSH:**

1. Список Environment → `+ Add SSH connection`
2. Заполни: Name, SSH Host (`user@hostname`), SSH Port (по умолчанию 22), Identity File
3. Claude Code установится на удалённую машину сам при первом подключении

### Плановые задачи (Scheduled tasks)

🎨 **Образ:** плановая задача — как будильник для агента. Ты лёг спать, агент проснулся, сделал работу и снова уснул до следующего раза. Утром тебя ждёт готовый результат.

Создание: вкладка Code → **Routines** в боковой панели → **New routine** → **Local**.

**Поля:**

- **Name** — название (например, `morning-report`)
- **Instructions** — что должен сделать Claude (обычный текст, по-русски). Тут же выбирается рабочая папка: без неё задачу не сохранить
- **Schedule** — расписание

**Варианты расписания:**

| Вариант | Что значит |
|---|---|
| Manual | Только ручной запуск |
| Hourly | Каждый час |
| Daily | Каждый день в выбранное время |
| Weekdays | По будням в выбранное время |
| Weekly | Раз в неделю в выбранный день и час |

Минимальный интервал: **1 минута**. Интервал, которого нет в списке, можно задать словами: попроси Claude в любой сессии.

**Локальные и облачные:**

- Локальные задачи идут на твоём компьютере и видят твои файлы, но только пока приложение запущено, а компьютер не спит
- Облачные (routines) работают и при выключенном компьютере, их можно запускать через API (способ, которым программы обращаются друг к другу) или по событию на GitHub. Минимальный интервал — 1 час

**Совет:** если задача должна сработать ночью, включи **Keep computer awake** (`Settings → This computer → System`). Закрытая крышка ноутбука всё равно усыпит компьютер.

### Управление компьютером (Computer use)

🎨 **Образ:** Computer use — как дать агенту посмотреть на твой экран и взять мышь с клавиатурой. Он видит, что происходит, может щёлкать, печатать и прокручивать. Похоже на удалённый доступ, только что делать, решает сам агент.

- Нужен тариф **Pro или Max** (на Team и Enterprise недоступно). Функция в режиме research preview: это ранняя версия, которую ещё испытывают
- Включить: `Settings → This computer → System`, раздел **Computer use**
- На macOS нужно выдать системные разрешения Accessibility и Screen Recording

⚠️ Так агент действует прямо в твоих программах. Сначала пробуй на чём-то безобидном, а окна с банком и почтой на время опытов закрой.

**Три уровня доступа к программам:**

| Уровень | Программы |
|---|---|
| View only (только смотреть) | Браузеры, торговые платформы |
| Click only (только щёлкать) | Терминалы, редакторы кода |
| Full control (полный доступ) | Всё остальное |

### Приложение, расширение VS Code и терминал — сравнение

🎨 **Образ:** три инструмента для одного дела. Терминал (CLI) — скальпель: точный и гибкий в опытных руках. VS Code — редактор и агент в одном окне. Приложение — своя клиника: несколько операционных (сессий), своё оборудование (панели) и график дежурств (плановые задачи).

| Возможность | Терминал (CLI) | Приложение | VS Code |
|---|---|---|---|
| Несколько сессий сразу | В отдельных окнах терминала | ✅ В боковой панели | ✅ Во вкладках и окнах |
| Встроенный терминал | Сам работает в терминале | ✅ | ✅ (терминал VS Code) |
| Наглядный просмотр изменений | ❌ | ✅ | ✅ |
| Прикрепить файл или картинку | ❌ | ✅ | ✅ |

## Частые ошибки

❌ **Ошибка:** открыл приложение и остался во вкладке Chat, думая, что это и есть Claude Code.

✅ **Правильно:** Chat — просто разговор без доступа к файлам. Для работы с кодом нужна вкладка **Code**.

❌ **Ошибка:** включил Fable для каждой задачи, «чтобы было лучше».

✅ **Правильно:** для большинства повседневных задач хватает модели по умолчанию, а Sonnet быстрее и дешевле. Fable нужна для действительно долгих и сложных задач, и на части тарифов она оплачивается сверх подписки, через usage credits. Haiku — для быстрых простых просьб. Не трать лимит впустую.

❌ **Ошибка:** работаешь в режиме Bypass permissions с настоящими проектами и важными данными.

✅ **Правильно:** Bypass permissions — только для изолированной тестовой среды. В настоящих проектах выбирай Manual, Accept edits или Auto.

❌ **Ошибка:** запустил две сессии в одной папке и удивляешься, что они мешают друг другу.

✅ **Правильно:** сессии в одной папке правят одни и те же файлы. Дай им разные папки или включи опцию worktree: тогда у каждой будет своя копия проекта.

❌ **Ошибка:** включаешь опцию worktree, а Git не установлен.

✅ **Правильно:** для отдельной копии проекта нужен Git. На Windows поставь [Git for Windows](https://git-scm.com/download/win) и запусти сессию снова.

## Практика

**Задание: первый день в приложении**

В шагах указаны клавиши Mac; на Windows вместо Cmd нажимай Ctrl.

**Шаг 1 — Установка (10 мин):**

1. Скачай приложение по ссылке для своей системы (выше)
2. Установи как обычную программу
3. Запусти и войди в аккаунт Anthropic (нужен платный тариф)

**Шаг 2 — Осмотрись (5 мин):**

1. Открой вкладку Code вверху окна
2. Нажми `Cmd+/` и просмотри список горячих клавиш
3. Открой список моделей — посмотри, что доступно
4. Открой список режимов разрешений, прочитай про каждый и выбери Manual

**Шаг 3 — Первая сессия (10 мин):**

1. Нажми `Cmd+N` — новая сессия
2. В списке Environment оставь Local, нажми **Select folder** и выбери папку (для первого раза создай пустую тестовую)
3. Напиши: `Что ты видишь в этой папке? Расскажи, как она устроена.`
4. Посмотри, как агент изучает файлы

💡 Для самого первого раза бери тестовую папку, а не ту, где лежат важные документы. Проверь, что выбран режим Manual: тогда Claude спросит, прежде чем что-то менять.

**Шаг 4 — Две сессии сразу (5 мин):**

1. Нажми `Cmd+N` ещё раз — появится вторая сессия
2. В первой спроси одно, во второй другое
3. Переключайся между ними клавишами `Ctrl+Tab`
4. Убедись, что у каждой свой разговор

**Шаг 5 — Первая плановая задача (10 мин):**

1. Нажми **Routines** в боковой панели → **New routine** → **Local**
2. Name: `morning-check`
3. Instructions: `Проверь все файлы .md в папке и напиши, что нового появилось`. Выбери ту же тестовую папку
4. Schedule: Manual (пока только ручной запуск)
5. Сохрани задачу, нажми **Run now** и посмотри, как она отработает

Готово, если: приложение установлено, в тестовой папке агент ответил на вопрос, а задача `morning-check` запустилась и показала результат.

## Ключевые выводы

> Claude Code живёт в приложении Claude для компьютера, во вкладке Code. Chat — это просто разговор без доступа к файлам.

> Модели переключаются прямо во время работы. По умолчанию стоит Opus, Sonnet быстрее и дешевле, Haiku — для быстрых задач, Fable — для самых сложных.

> Пока учишься, выбирай режим Manual и тестовую папку: агент будет спрашивать перед каждым изменением.

> Плановые задачи — агент по расписанию. Локальные работают, только пока приложение запущено, а компьютер не спит.
