# AI презентации — Gamma, Beautiful.ai и PowerPoint через Claude

**Модуль:** Content Factory AI | **Время:** ~25 мин теории + 35 мин практики

---

## Суть урока

Сделать хорошую презентацию раньше занимало день работы в PowerPoint — AI инструменты превращают это в 20-минутный процесс, где ты фокусируешься на идеях, а не на расположении блоков на слайде.

🎨 **Образ:** Обычный PowerPoint — это самому строить мебель по инструкции IKEA: детали правильные, но уходит весь день и половина болтиков лишняя. Gamma AI — это мебель которую привозят уже собранной. Ты только говоришь какую хочешь, и через 5 минут она стоит в комнате. Потом двигаешь что не так.

---

## Ключевые концепции

- Gamma AI — полная презентация из одного промпта (промпт — запрос к AI), адаптивный дизайн
- Beautiful.ai — AI-дизайн слайдов с умными шаблонами (шаблон — готовый макет)
- Claude + python-pptx — генерация PowerPoint файлов кодом (полный контроль)
- Claude + Google Slides API (эй-пи-ай — интерфейс программирования) — презентации в облаке через код
- Workflow (воркфлоу — рабочий процесс): идея → структура через Claude → дизайн через Gamma → финальные правки
- Pitch deck (питч-дек — презентация для инвесторов) через AI — от концепции до инвестора за несколько часов

## Теория

### Gamma AI — презентация из одного промпта

Gamma ([gamma.app](https://gamma.app)) — один из самых быстрых путей от идеи до красивой презентации.

**Как работает:**

1. Вводишь одно предложение или пасту текста
2. Gamma предлагает структуру (ты редактируешь)
3. Gamma генерирует дизайн
4. Ты настраиваешь детали

**Типы контента который генерирует:**

- Презентации (slides)
- Документы (docs с красивым форматированием)
- Веб-страницы (публичные лендинги)

**Ценообразование (на октябрь 2026):** у Gamma есть бесплатный старт, генерация работает на кредитах, а лимиты и условия экспорта зависят от тарифа. Актуальное: [gamma.app/pricing](https://gamma.app/pricing), [Актуальное сейчас](https://aimayak.com/ru/now/).

**Что Gamma умеет хорошо:**

- Адаптивная вёрстка под любой контент
- Автоматическая типографика
- Встроенные изображения по теме
- Интерактивные элементы (графики, embed)
- Gamma Agent: в чате меняет стиль, текст и тон по всей колоде сразу (с Gamma 3.0)
- Smart Diagrams: рисует схемы по описанию
- Русский язык — проверь на своём тексте до того, как строить на нём процесс

🎨 **Образ:** Gamma — это как хороший дизайнер-верстальщик на аутсорсе: ты говоришь что нужно, он делает красиво, ты говоришь что изменить, он меняет. Не идеально, но 80% работы уже сделано.

### Beautiful.ai — умные шаблоны слайдов

Beautiful.ai ([beautiful.ai](https://beautiful.ai)) отличается от Gamma подходом: главное — чтобы слайды выглядели профессионально автоматически. Есть и режим Create with AI: задаёшь тему или план, уточняешь структуру и получаешь дизайн.

**Ключевая фича — Smart Slides:**
Когда добавляешь элемент (текст, картинку, иконку), слайд автоматически перестраивается чтобы всё выглядело правильно. Нельзя сделать «криво» — система не позволит.

| | Gamma | Beautiful.ai |
|--|-------|--------------|
| Генерация из промпта | ✅ Да | ✅ Да (Create with AI) |
| Дизайн-контроль | Средний | Высокий |
| Умные шаблоны | Базовые | Продвинутые |
| Совместная работа | ✅ Да | ✅ Да |
| Экспорт PPTX | зависит от тарифа | зависит от тарифа |
| Цена | см. страницу тарифов | см. страницу тарифов (пробный период 14 дней) |

**Когда использовать Beautiful.ai вместо Gamma:**

- Нужен больший контроль над дизайном
- Командная работа над презентацией
- Корпоративный стиль с точным соблюдением гайдлайнов

**Если ты живёшь в PowerPoint или Google Slides:** Copilot в PowerPoint (режим Agent Mode) и Gemini в Google Slides тоже собирают презентацию из запроса. Нужны подходящие подписки (Microsoft 365 с Copilot или тарифы Google Workspace и Google AI), и функции раскатываются постепенно. Для русскоязычных презентаций проверь поддержку языка: Gemini в Slides на запуске работал только на английском.

### Claude + python-pptx — PowerPoint через код

Когда нужен полный контроль или генерация многих презентаций автоматически — Claude пишет код который создаёт PPTX файлы.

**Установка:**

```bash
pip install python-pptx
```

**Базовый пример — Claude генерирует презентацию из структуры:**

```python
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN

def create_presentation(title, slides_data):
    """
    slides_data = [
        {"title": "Заголовок", "content": ["пункт 1", "пункт 2"]},
        ...
    ]
    """
    prs = Presentation()
    
    # Размер слайда (широкоформатный 16:9)
    prs.slide_width = Inches(13.33)
    prs.slide_height = Inches(7.5)
    
    # Титульный слайд
    slide_layout = prs.slide_layouts[0]
    slide = prs.slides.add_slide(slide_layout)
    slide.shapes.title.text = title
    slide.placeholders[1].text = "Создано через Claude + python-pptx"
    
    # Слайды с контентом
    for slide_data in slides_data:
        slide_layout = prs.slide_layouts[1]  # заголовок + контент
        slide = prs.slides.add_slide(slide_layout)
        
        # Заголовок
        slide.shapes.title.text = slide_data["title"]
        
        # Контент
        tf = slide.placeholders[1].text_frame
        tf.clear()
        for i, point in enumerate(slide_data["content"]):
            if i == 0:
                tf.text = point
            else:
                p = tf.add_paragraph()
                p.text = point
                p.level = 0
    
    return prs

# Использование
slides = [
    {"title": "Проблема", "content": [
        "Проблема 1: ...",
        "Проблема 2: ...",
        "Проблема 3: ..."
    ]},
    {"title": "Наше решение", "content": [
        "Как мы решаем проблему 1",
        "Как мы решаем проблему 2"
    ]},
]

prs = create_presentation("Pitch Deck — Название проекта", slides)
prs.save("presentation.pptx")
print("Готово!")
```

**Промпт для Claude:** «Напиши Python скрипт который создаёт профессиональный pitch deck для [описание проекта]. Используй python-pptx. 10 слайдов: проблема, решение, рынок, продукт, бизнес-модель, команда, трекшн, финансы, план, CTA.»

### Claude + Google Slides API — презентации в облаке

Для командной работы и автоматической генерации в облаке — Google Slides API.

**Почему это полезно:**

- Презентация сразу в Google Drive (доступна всем)
- Можно обновлять автоматически (например, квартальные отчёты)
- Нет зависимости от PPTX и локальных файлов

**Настройка:**

```bash
pip install google-auth google-auth-httplib2 google-api-python-client
```

**Базовый код:**

```python
from google.oauth2 import service_account
from googleapiclient.discovery import build

# Настройка авторизации
SCOPES = ['https://www.googleapis.com/auth/presentations']
credentials = service_account.Credentials.from_service_account_file(
    'service-account-key.json', scopes=SCOPES
)

service = build('slides', 'v1', credentials=credentials)

# Создать новую презентацию
presentation = service.presentations().create(
    body={"title": "Моя AI-презентация"}
).execute()

presentation_id = presentation['presentationId']
print(f"Создана: https://docs.google.com/presentation/d/{presentation_id}")
```

Дальше Claude помогает написать батч-запросы для добавления слайдов, текста, изображений.

### Workflow: идея → Claude → Gamma → финал

Оптимальный процесс для большинства презентаций:

**Шаг 1: Структура через Claude (5 мин)**

```
Задача: презентация [тема] для [аудитория]
Цель: [что должна сделать аудитория после]
Длина: [N слайдов]

Создай структуру:
- Заголовок каждого слайда
- 3-5 тезисов для каждого
- Рекомендации по визуалу
```

**Шаг 2: Генерация в Gamma (5 мин)**

- Вставляешь структуру от Claude в Gamma
- Выбираешь тему оформления
- Gamma генерирует дизайн

**Шаг 3: Правки в Gamma (10-15 мин)**

- Корректируешь формулировки
- Меняешь изображения если нужно
- Убираешь лишнее

**Шаг 4: Финальный review через Claude (5 мин)**

```
[Вставить финальные тезисы всех слайдов]

Проверь:
1. Логика от слайда к слайду — есть ли сюжет?
2. Каждый слайд одна мысль или несколько?
3. Призыв к действию последнего слайда — конкретный?
4. Есть ли противоречия между слайдами?
```

Итого: 25-30 минут на профессиональную презентацию.

### Pitch deck через AI для инвесторов

Pitch deck — особый формат: жёсткая структура, очень мало текста, максимум цифр.

**Стандартная структура (10-12 слайдов):**

```
1. Титул — название, tagline, контакты
2. Проблема — конкретная боль, размер проблемы
3. Решение — как вы решаете, 1 предложение
4. Продукт — скриншоты, демо, 3 ключевых фичи
5. Рынок — TAM, SAM, SOM с источниками
6. Бизнес-модель — как зарабатываете
7. Трекшн — рост, метрики, клиенты
8. Конкуренты — матрица сравнения
9. Команда — фото + 1 строка почему вы
10. Финансы — P&L прогноз 3 года
11. Запрос — сколько, на что, runway
12. Благодарность — контакт + follow-up
```

**Промпт для Claude:**

```
Создай структуру pitch deck для [описание стартапа].
Инвесторы: [тип инвесторов, стадия].
Раунд: [pre-seed / seed / series A], сумма: [N].

Для каждого слайда:
- Заголовок (до 5 слов)
- 3 главных тезиса (конкретные цифры где возможно)
- Какие данные нужны для слайда
- Что НЕ стоит писать (частые ошибки этого слайда)
```

🎨 **Образ:** Pitch deck — это резюме для инвестора. Хорошее резюме не объясняет каждый опыт подробно, оно показывает главное быстро. Если инвестор тратит больше 3 минут на твои 12 слайдов — что-то не так.

## Практика

1. Создай аккаунт в Gamma (бесплатно, Google login):

Зайди на [gamma.app](https://gamma.app) → New → «Generate» → выбери «Presentation» (названия кнопок в интерфейсе меняются)

2. Попроси Claude создать структуру для твоей презентации:

```
Тема: [выбери актуальную — описание своего проекта, 
курса, услуги или идеи]
Аудитория: [кто будет смотреть]
Цель: [что должны сделать после]
Слайдов: 10

Создай структуру: заголовок каждого слайда + 
3-4 тезиса для каждого.
```

3. Вставь структуру в Gamma, выбери тему, сгенерируй презентацию

4. Попроси Claude улучшить первые 3 слайда:

```
[Вставь текст первых 3 слайдов из Gamma]

Для каждого слайда предложи:
- Более сильный заголовок (до 6 слов)
- Убери общие слова, добавь конкретику
- Первый тезис — самый важный факт
```

5. Установи python-pptx и создай простую презентацию через код:

```bash
pip install python-pptx
```

```python
# Попроси Claude написать скрипт для 5-слайдовой презентации

```

6. Для продвинутых — создай автоматический генератор еженедельных отчётов:

```
Попроси Claude написать скрипт который:

2. Генерирует PPTX с 4 слайдами: 
   - Основные показатели
   - Что сделали
   - Что не получилось
   - Планы на следующую неделю
3. Сохраняет с датой в названии
```
