# AI презентации — Gamma, Beautiful.ai и PowerPoint через Claude

**Время:** ~25 мин теории + 35 мин практики

---

## Суть урока

Хорошая презентация раньше отнимала день работы в PowerPoint. С AI аккуратный черновик собирается примерно за полчаса: ты думаешь об идеях, а не о расположении блоков на слайде.

Основная часть урока проходится в браузере, без кода. Разделы про python-pptx и Google Slides API — для тех, кто строит свои инструменты; остальные их пропускают.

🎨 **Образ:** Обычный PowerPoint — это самому собирать мебель по инструкции IKEA: детали правильные, но уходит весь день и половина болтиков лишняя. Gamma — это мебель, которую привозят уже собранной. Ты только говоришь, какую хочешь, и через 5 минут она стоит в комнате. Потом двигаешь то, что стоит не так.

---

## Ключевые концепции

- Gamma — готовая презентация из одного промпта (промпт — запрос к AI), макет сам подстраивается под содержание
- Beautiful.ai — оформление слайдов с умными шаблонами (шаблон — готовый макет)
- Claude + python-pptx — файлы PowerPoint создаёт код (полный контроль; для тех, кто строит)
- Claude + Google Slides API (API, «эй-пи-ай», — способ, которым одна программа обращается к другой) — презентации в облаке через код
- Рабочий процесс: идея → структура в Claude → оформление в Gamma → финальные правки
- Питч-дек (pitch deck, презентация для инвесторов) с помощью AI: от замысла до черновика за несколько часов

## Теория

### Gamma AI — презентация из одного промпта

Gamma ([gamma.app](https://gamma.app)) — один из самых быстрых путей от идеи до аккуратной презентации.

**Как работает:**

1. Пишешь одно предложение или вставляешь готовый текст
2. Gamma предлагает структуру (ты её правишь)
3. Gamma создаёт оформление
4. Ты доводишь детали

**Что умеет создавать:**

- Презентации
- Документы с аккуратным оформлением
- Веб-страницы (публичные одностраничные сайты)

**Цены (на октябрь 2026):** у Gamma есть бесплатный старт, генерация расходует кредиты, а лимиты и условия экспорта зависят от тарифа. По справке Gamma, на бесплатном тарифе стартовый запас кредитов сам не пополняется, так что трать его на настоящую задачу. Цены Gamma: [gamma.app/pricing](https://gamma.app/pricing). Цены AI-ассистентов: [Актуальное сейчас](https://aimayak.com/ru/now/).

**Что Gamma умеет хорошо:**

- Макет, который подстраивается под любое содержание
- Автоматический подбор шрифтов и отступов
- Встроенные изображения по теме
- Интерактивные элементы (графики, встроенные видео и страницы)
- Gamma Agent: в чате меняет стиль, текст и тон во всей презентации сразу (появился в Gamma 3.0)
- Smart Diagrams («умные схемы»): рисует схемы по описанию
- Языки: по справке Gamma, запрос можно писать на своём языке, а в списке языков интерфейса есть русский. Качество текста всё равно проверь на своей теме

🎨 **Образ:** Gamma — как хороший дизайнер-верстальщик на подряде: ты говоришь, что нужно, он делает красиво; говоришь, что изменить, он меняет. Не идеально, но большая часть работы уже сделана.

### Beautiful.ai — умные шаблоны слайдов

Beautiful.ai ([beautiful.ai](https://beautiful.ai)) подходит к задаче иначе, чем Gamma: главное, чтобы слайды сами выглядели профессионально. Есть и режим Create with AI («создать с AI»): задаёшь тему или план, уточняешь структуру и получаешь оформление.

**Главная возможность — Smart Slides («умные слайды»):**
Когда добавляешь элемент (текст, картинку, значок), слайд сам перестраивается, чтобы всё стояло ровно. Сделать «криво» система не даст.

| | Gamma | Beautiful.ai |
|--|-------|--------------|
| Создание по промпту | ✅ Да | ✅ Да (Create with AI) |
| Контроль над оформлением | Средний | Высокий |
| Умные шаблоны | Базовые | Продвинутые |
| Совместная работа | ✅ Да | ✅ Да |
| Экспорт в PPTX (формат PowerPoint) | зависит от тарифа | зависит от тарифа |
| Цена | см. страницу тарифов | см. страницу тарифов (там же условия пробного периода) |

Строки «Контроль над оформлением» и «Умные шаблоны» — оценка автора, а не результат независимого сравнения: проверь на своей задаче.

**Когда использовать Beautiful.ai вместо Gamma:**

- Нужен больший контроль над оформлением
- Над презентацией работает команда
- Есть фирменный стиль, который нужно соблюдать точно

**Если ты живёшь в PowerPoint или Google Slides:** Copilot в PowerPoint (режим Agent Mode) и Gemini в Google Slides тоже собирают презентацию по запросу. Нужны подходящие подписки (Microsoft 365 с Copilot или тарифы Google Workspace и Google AI), и функции включаются у пользователей постепенно. Для презентаций на русском проверь поддержку языка: Gemini в Slides на запуске работал только на английском.

### Для тех, кто строит: Claude + python-pptx, PowerPoint через код

Этот раздел и следующий необязательные: они для тех, кто пишет код. Если ты не программируешь, переходи к разделу «Рабочий процесс». Когда нужен полный контроль или много однотипных презентаций, Claude пишет код, который создаёт файлы PPTX (формат PowerPoint).

**Установка:**

```bash
pip install python-pptx
```

**Базовый пример — код собирает презентацию по готовой структуре:**

```python
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.dml.color import RGBColor
from pptx.enum.text import PP_ALIGN

def create_presentation(title, slides_data):
    """
    slides_data = [
        {"title": "Заголовок", "content": ["пункт 1", "пункт 2"]},
        ...
    ]
    """
    prs = Presentation()
    
    # Размер слайда (широкоформатный 16:9)
    prs.slide_width = Inches(13.33)
    prs.slide_height = Inches(7.5)
    
    # Титульный слайд
    slide_layout = prs.slide_layouts[0]
    slide = prs.slides.add_slide(slide_layout)
    slide.shapes.title.text = title
    slide.placeholders[1].text = "Создано через Claude + python-pptx"
    
    # Слайды с содержанием
    for slide_data in slides_data:
        slide_layout = prs.slide_layouts[1]  # заголовок + текст
        slide = prs.slides.add_slide(slide_layout)
        
        # Заголовок
        slide.shapes.title.text = slide_data["title"]
        
        # Текст
        tf = slide.placeholders[1].text_frame
        tf.clear()
        for i, point in enumerate(slide_data["content"]):
            if i == 0:
                tf.text = point
            else:
                p = tf.add_paragraph()
                p.text = point
                p.level = 0
    
    return prs

# Использование
slides = [
    {"title": "Проблема", "content": [
        "Проблема 1: ...",
        "Проблема 2: ...",
        "Проблема 3: ..."
    ]},
    {"title": "Наше решение", "content": [
        "Как мы решаем проблему 1",
        "Как мы решаем проблему 2"
    ]},
]

prs = create_presentation("Питч-дек — Название проекта", slides)
prs.save("presentation.pptx")
print("Готово!")
```

**Промпт для Claude:** «Напиши скрипт на Python, который создаёт презентацию для инвесторов по описанию: [описание проекта]. Используй python-pptx. 10 слайдов: проблема, решение, рынок, продукт, бизнес-модель, команда, первые результаты, финансы, план, призыв к действию.»

### Claude + Google Slides API — презентации в облаке

Для командной работы и автоматического создания презентаций в облаке есть Google Slides API. Этот раздел тоже для тех, кто строит.

**Почему это полезно:**

- Презентация сразу появляется в твоём Google Drive, и ты сам открываешь к ней доступ команде
- Можно обновлять автоматически (например, квартальные отчёты)
- Не нужны файлы PPTX на своём компьютере

**Настройка:**

```bash
pip install google-api-python-client google-auth-httplib2 google-auth-oauthlib
```

В Google Cloud Console включи Google Slides API, создай OAuth-клиент типа Desktop app и скачай его файл как `credentials.json` (по шагам это описано в документации Google Slides API, ссылка в конце урока).

**Базовый код:**

```python
from google_auth_oauthlib.flow import InstalledAppFlow
from googleapiclient.discovery import build

# Настройка авторизации: откроется браузер, войди в свой аккаунт Google
SCOPES = ['https://www.googleapis.com/auth/presentations']
flow = InstalledAppFlow.from_client_secrets_file('credentials.json', SCOPES)
credentials = flow.run_local_server(port=0)

service = build('slides', 'v1', credentials=credentials)

# Создать новую презентацию
presentation = service.presentations().create(
    body={"title": "Моя AI-презентация"}
).execute()

presentation_id = presentation['presentationId']
print(f"Создана: https://docs.google.com/presentation/d/{presentation_id}")
```

Дальше Claude помогает написать пакетные запросы, которые добавляют слайды, текст и изображения.

⚠️ Файл `credentials.json` храни как пароль: не клади его в общие папки, письма и открытые хранилища кода.

### Рабочий процесс: идея → Claude → Gamma → финал

Удобный порядок для большинства презентаций:

**Шаг 1: Структура в Claude (5 мин)**

```
Задача: презентация [тема] для [аудитория]
Цель: [что должна сделать аудитория после]
Длина: [N слайдов]

Создай структуру:
- Заголовок каждого слайда
- 3-5 тезисов для каждого
- Что показать на слайде: схему, фото, график
```

**Шаг 2: Создание в Gamma (5 мин)**

- Вставляешь структуру от Claude в Gamma
- Выбираешь тему оформления
- Gamma создаёт слайды

**Шаг 3: Правки в Gamma (10-15 мин)**

- Правишь формулировки
- Меняешь изображения, если нужно
- Убираешь лишнее

**Шаг 4: Финальная проверка в Claude (5 мин)**

```
[Вставить финальные тезисы всех слайдов]

Проверь:
1. Логика от слайда к слайду — есть ли сюжет?
2. На каждом слайде одна мысль или несколько?
3. Призыв к действию на последнем слайде — конкретный?
4. Есть ли противоречия между слайдами?
```

Итого: 25-30 минут на аккуратный черновик презентации. Факты и цифры на слайдах проверяешь ты.

### Питч-дек для инвесторов с помощью AI

Питч-дек — особый формат: жёсткая структура, очень мало текста, максимум цифр.

**Стандартная структура (10-12 слайдов):**

```
1. Титул — название, слоган, контакты
2. Проблема — конкретная боль и её масштаб
3. Решение — как вы решаете проблему, одним предложением
4. Продукт — снимки экрана, показ в работе, 3 главные возможности
5. Рынок — TAM, SAM, SOM с источниками
6. Бизнес-модель — на чём зарабатываете
7. Первые результаты — рост, показатели, клиенты
8. Конкуренты — таблица сравнения
9. Команда — фото + 1 строка, почему именно вы
10. Финансы — прогноз доходов и расходов на 3 года
11. Запрос — сколько денег нужно, на что и на сколько месяцев их хватит
12. Спасибо — контакты и следующий шаг
```

TAM, SAM и SOM — три оценки размера рынка: весь рынок, та его часть, которую ты способен обслужить, и доля, которую реально занять.

Каждую цифру о рынке сверь с источником. AI может уверенно выдумать число (это называется галлюцинацией), а неверный размер рынка на пятом слайде может стоить всей встречи.

**Промпт для Claude:**

```
Создай структуру презентации для инвесторов. Стартап: [описание].
Инвесторы: [тип инвесторов, стадия].
Раунд: [название раунда, например посевной (seed)], сумма: [N].

Для каждого слайда:
- Заголовок (до 5 слов)
- 3 главных тезиса (конкретные цифры, где возможно)
- Какие данные нужны для слайда
- Что НЕ стоит писать (частые ошибки этого слайда)
```

🎨 **Образ:** Питч-дек — это резюме для инвестора. Хорошее резюме не расписывает каждое место работы, оно быстро показывает главное. Если инвестору нужно больше 3 минут на твои 12 слайдов — что-то не так.

## Практика

1. Создай аккаунт в Gamma (бесплатно, можно войти через Google):

Зайди на [gamma.app](https://gamma.app) → Create new AI. Там два нужных режима: Generate (презентация по короткому запросу) и Paste in text (презентация по готовому тексту или плану). Названия кнопок в интерфейсе со временем меняются

2. Попроси Claude создать структуру для твоей презентации:

```
Тема: [выбери настоящую — описание своего проекта, 
курса, услуги или идеи]
Аудитория: [кто будет смотреть]
Цель: [что должны сделать после]
Слайдов: 10

Создай структуру: заголовок каждого слайда + 
3-4 тезиса для каждого.
```

3. В Gamma выбери Paste in text, вставь структуру, выбери Presentation и тему оформления, создай презентацию

4. Попроси Claude улучшить первые 3 слайда:

```
[Вставь текст первых 3 слайдов из Gamma]

Для каждого слайда предложи:
- Более сильный заголовок (до 6 слов)
- Убери общие слова, добавь конкретику
- Первый тезис — самый важный факт
```

Готово, когда у тебя есть презентация на 10 слайдов, которую можно показать: факты и цифры на слайдах проверены тобой. На этом практика без кода закончена.

5. Необязательно, для тех, кто строит: установи python-pptx и создай простую презентацию через код:
